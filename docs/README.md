# 开发文档

机械设计物料选型引擎（MDS）的完整开发文档。

## 五分钟了解这个项目

它把一份 Claude skill 的六阶段选型工作流，做成了一款离线可用、过程可逐行验证的桌面软件。

**一句话说清它和别的选型工具的区别**：这里的每一个数字都能追溯到公式、代入值和数据出处；
算不出来的时候它会停下来说算不出来，而不是给一个看起来合理的数。

三条贯穿全项目的硬规则，任何改动都不能破坏：

| 规则 | 含义 | 在哪里落实 |
|---|---|---|
| **拒绝外推** | 工况超出数据表覆盖范围 → 报缺口，绝不返回数字 | [`mds/tables.py`](../engine/mds/tables.py) |
| **AI 不碰计算** | AI 的建议值必须过与手输相同的校验闸门 | [`server/ai/tasks.py`](../server/ai/tasks.py) |
| **置信度是事实** | 🟢/🟡/🔴 读自数据表真实状态，标绿必须有第二信源 | [`mds/editor.py`](../engine/mds/editor.py) |

## 当前能力边界

诚实地说清楚它现在能做什么、不能做什么——这比功能列表更重要：

**能做**：12 个物料的完整六阶段选型，离线可用，出 PDF/Excel 报告，
生成采购链接，数据缺口自检。95 个代表性工况里 81 个能算到底。

**不能做**：有限元与动力学仿真（有意划的边界）；
齿轮的完整强度校核与链传动的链号选择（关键系数是线图，读不出数）；
手机端离线计算。

**最大的短板**：**25 张数据表 0 张完成双源核验**。
两处电子转载互校只能到 🟡，标 🟢 需要标准原件或纸质手册。
软件本身可用，但数据不够硬——这是"能用"和"敢用"之间唯一的距离。
详见[知识库与数据](knowledge.md#当前数据状态)。
