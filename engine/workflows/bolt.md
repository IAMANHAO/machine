# 螺栓（受拉紧螺栓连接）选型工作流

> **本文档与 `bolt.yaml` 的关系**
>
> `bolt.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是**人读说明与评审物**，与 YAML 逐条对齐。
> 改公式先改 YAML，再回填本文档；若有出入以 YAML 为准。

## 基本信息

- 物料类型：螺栓连接（受轴向静载荷的**紧螺栓连接**）
- 主导标准：
  - **GB/T 196**《普通螺纹 基本尺寸》—— 粗牙系列 d / P / d2 / d1
  - **GB/T 3098.1-2010**《紧固件机械性能 螺栓、螺钉和螺柱》（等效 ISO 898-1）—— 性能等级
  - **GB/T 16823.1-1997**《螺纹紧固件应力截面积和承载面积》—— As
- 主要信源：上述标准的公开电子转载 + 嘉立创FA 机械设计手册在线版
- 覆盖范围：**粗牙螺纹 M3 ~ M64**，性能等级 4.6 ~ 12.9

**不覆盖**：细牙螺纹、受剪螺栓、受横向载荷的铰制孔螺栓、螺栓组的载荷分配、
疲劳强度校核。原因见「未实现项」。

## 选型目标

确定：螺栓规格（M 号）、公称直径 d、螺距 P、应力截面积 As、
许用应力 [σ]、实际工作应力、设计预紧力 F0、**拧紧力矩区间**。

## 输入参数

与 `yaml: inputs` 一一对应。「域」一列是引擎实际执行的取值范围。

### 必填

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 螺栓所受总拉力 | `F0_total` | N | 1 ~ 10000000 | **已含残余预紧力与工作载荷分量**，不是工作载荷本身 |
| 受力螺栓个数 | `z` | — | 1 ~ 200 | 默认 1。总拉力在这些螺栓间均分 |
| 性能等级 | `grade` | — | 枚举 | 默认 8.8 级。选项读自 `property_class.classes` |
| 材料类别 | `material_class` | — | `carbon_steel` / `alloy_steel` | 决定预紧力系数与安全系数取哪一行 |
| 预紧力控制方式 | `preload_control` | — | `uncontrolled` / `controlled` | 默认不控制 |
| 表面状态与润滑 | `surface` | — | 枚举 | 默认干态。选项读自 `torque_coeff.by_surface` |

### 分支必填

| 参数 | id | 域 | 何时必填 |
|---|---|---|---|
| 假定直径档 | `d_band` | `d_le_16` / `d_16_to_30` / `d_30_to_60` | `preload_control == 'uncontrolled'` |

> **为什么要用户假定一个直径档？**
>
> 不控制预紧力时安全系数按直径分档，而直径要算完才知道——这是个迭代。
> 本工作流把迭代**显式化**：你先假定一档，末尾有两步校核确认算出的规格
> 确实落在该档内，不落在就告诉你改选哪一档重算。
>
> 与其把迭代藏进代码里悄悄跑两遍，不如让它出现在计算过程里。
> 控制预紧力时 S 与直径无关，这一项自动不适用，不会逼你选一个用不上的档位。

### 枚举取值

| 参数 | 可选值 |
|---|---|
| `grade` | `c4_6` `c4_8` `c5_6` `c5_8` `c6_8` `c8_8` `c9_8` `c10_9` `c12_9`（键里不能带点，真正的代号在表的 `code` 字段） |
| `material_class` | `carbon_steel` 碳素钢 ／ `alloy_steel` 合金钢 |
| `preload_control` | `uncontrolled` 不控制（凭手感）／ `controlled` 控制（力矩扳手 / 转角法 / 测伸长量） |
| `surface` | `general_lubricated` `general_dry` `phosphated_hs_bolt` `phosphated_dry` `phosphate_soap` `dacromet_dry` `zinc_plated_dry` `black_oxide_dry` |

## 计算步骤

共 **20 个 step**，分属下面 5 段。每行的「步骤 id」即 YAML 里的 `- id:`。

### 第 1 步：材料强度

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `sigma_s` | 查表 | `property_class.classes.{grade}.sigma_s`（MPa） |
| `grade_code` | 查表 | `classes.{grade}.code` —— 显示与采购用的等级代号 |
| `Rm` | 查表 | `classes.{grade}.Rm`（MPa） |

> **等级代号本身就是数据来源。** GB/T 3098.1 规定：代号点左边 = Rm 的 1/100，
> 点右边 = 屈强比 × 10。所以 8.8 → Rm = 800 MPa，σs = 640 MPa。
> 这张表不是抄来的一组数，而是**规则的展开**，测试会逐行反推校验。

| 等级 | Rm (MPa) | σs (MPa) |
|---|---|---|
| 4.6 | 400 | 240 |
| 4.8 | 400 | 320 |
| 5.6 | 500 | 300 |
| 5.8 | 500 | 400 |
| 6.8 | 600 | 480 |
| **8.8** | **800** | **640** |
| 9.8 | 900 | 720 |
| 10.9 | 1000 | 900 |
| 12.9 | 1200 | 1080 |

> 4.8 / 5.8 / 6.8 的屈服值在标准里是**规定非比例延伸应力**（Rpf / Rp0.2），
> 不是下屈服强度 ReL。工程上同样用于算许用应力，但报告里不要写成"屈服强度"。

### 第 2 步：安全系数与许用应力

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `S_controlled` | 查表 | 仅 `controlled`；取 `safety_factor.controlled.S` = 1.5 |
| `S_uncontrolled` | 查表 | 仅 `uncontrolled`；取 `uncontrolled.{material_class}.{d_band}.S` |
| `sigma_allow` | 公式 | **[σ] = σs / S**（MPa） |

| 控制方式 | 材料 | M6~M16 | M16~M30 | M30~M60 |
|---|---|---|---|---|
| 不控制 | 碳素钢 | 4.0 | 3.5 | 3.0 |
| 不控制 | 合金钢 | **缺数据** | **缺数据** | **缺数据** |
| 控制 | 不分材料与直径 | 1.5 | 1.5 | 1.5 |

> **小直径螺栓的 S 反而更大**，因为不控制预紧力时它容易被拧过头拧断。
>
> **合金钢 + 不控制预紧力整档没有数据**：信源只给了笼统的「5.0~5.5」，
> 没有按直径分档，硬填等于编数。选到这个组合会如实报出缺口位置
> （`safety_factor.yaml` 的 `uncontrolled.alloy_steel` 下缺哪一档），
> 而**不会**退到碳素钢那一行凑合。

### 第 3 步：所需截面积与选规格

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `As_req` | 公式 | **As′ = 1.3 F0 / (z · [σ])**（mm²） |
| `bolt_size` | **选行** | 在 `thread_series.coarse` 里按 `As` 升序取第一个 `As ≥ As_req` 的行，取回 `label` / `d` / `P` / `As` |

> **1.3 是紧螺栓连接的扭转附加系数**：拧紧时螺栓同时受拉与受扭，按拉伸当量放大。
>
> `bolt_size` 是全项目第一个 `row_select` 步骤。用 `round_to_series` 做不到——
> 它只圆整扁平数字列表，拿不回同一行的 d 与 P。绕开的办法是把同一份数据
> 存两遍（一份扁平系列 + 一份反查字典），那正是这个项目最该避免的事。
>
> **没有"取最接近的一行"这个退路。** 所需截面积超出 M64 就是超出了，
> 引擎判定**系列内无解**并建议提高强度等级或增加螺栓数——
> 给一个比所需规格更小的螺栓，比停下来说无解危险得多。

### 第 4 步：强度与假定档校核

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `sigma_actual` | 公式 | **σ实 = 1.3 F0 / (z · As)**（MPa） |
| `chk_strength` | 校核 | σ实 ≤ [σ] |
| `band_lo` / `band_hi` | 查表 | 仅 `uncontrolled`；取假定档的直径上下界 |
| `chk_band_lo` / `chk_band_hi` | 校核 | 仅 `uncontrolled`；算出的 d 必须落在假定档内 |

### 第 5 步：预紧力与拧紧力矩

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `preload_ratio` | 查表 | `torque_coeff.preload_ratio.{material_class}.min` |
| `F_pre` | 公式 | **F0 = 系数 × σs × As**（N） |
| `K_pick` | 决策表 | `torque_coeff.by_surface.{surface}` → `K_min` / `K_max` |
| `T_min` / `T_max` | 公式 | **T = K · F0 · d / 1000**（N·m） |
| `T_label` | 文本 | `173.3 ~ 202.2 N·m（一般加工表面 · 无润滑）` |

预紧力推荐值：碳素钢 F0 = (0.6~0.7) σs·As，合金钢 F0 = (0.5~0.6) σs·As。
**本工作流取区间下端**（0.6 / 0.5），偏保守。

| 表面状态 | K 区间 |
|---|---|
| 一般加工表面 · 有润滑 | 0.13 ~ 0.15 |
| **一般加工表面 · 无润滑** | **0.18 ~ 0.21** |
| 磷化高强度螺栓（手册口径） | 0.11 ~ 0.15 |
| 磷化 · 干态（实测口径） | 0.18 ~ 0.25 |
| 磷皂化 · 干态 | 0.13 ~ 0.18 |
| 达克罗 · 干态 | 0.15 ~ 0.25 |
| 镀锌 · 干态 | 0.25 ~ 0.30 |
| 发黑 · 干态 | 0.25 ~ 0.30 |

> **拧紧力矩输出的是区间，不是单值。** K 把螺纹副摩擦与支承面摩擦一起打包成
> 一个经验系数，随表面状态、润滑、垫圈、拧紧速度变化。
> 给一个精确到小数点后两位的单值，是在用精度冒充准确。
>
> 注意表里**磷化有两个口径且相互冲突**（0.11~0.15 vs 0.18~0.25）：
> 手册口径可能指磷皂化处理后的高强度螺栓连接副，实测口径是干态磷化。
> 两者分列两项、各自标注，**没有取平均、没有合并**。

## 校核条件

引擎实际执行的 **3 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 | 适用分支 |
|---|---|---|---|---|
| `chk_strength` | 拉伸强度 | σ实 ≤ [σ] | 提高性能等级、增加螺栓个数，或改用更大规格 | 全部 |
| `chk_band_lo` | 假定直径档下界 | d ≥ 档下界 | 算出的规格小于假定档，S 取小了，改选更小的档重算 | 仅不控制预紧力 |
| `chk_band_hi` | 假定直径档上界 | d ≤ 档上界 | 算出的规格超出假定档，S 取大了，改选更大的档重算 | 仅不控制预紧力 |

> **「所需截面积超出 M64」不是校核项。** 它由 `bolt_size` 的选行失败处理：
> 判定**系列内无解**，给出「改用更高强度等级或增加螺栓数」的出路。
> 做成 check 会产生一个"算出了规格但不通过"的假象——实际上那个规格根本不存在。

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| 由工作载荷推总拉力 | 需要相对刚度系数 C（被连接件与垫片的刚度比），缓存里没有这张表 | 一张 C 的推荐值表（按垫片材质与被连接件） |
| 受剪螺栓（铰制孔） | 缺许用挤压应力 `[σp]` 与许用切应力 `[τ]` 的表 | 两张许用应力表（按被连接件材料） |
| 合金钢 + 不控制预紧力 | 信源只给笼统的「5.0~5.5」，没按直径分档 | 成大先《机械设计手册》或濮良贵《机械设计》原书的完整表 |
| 螺栓长度 | 取决于被连接件总厚度、垫圈、螺母高度与伸出量，属结构尺寸而非强度计算 | 不打算做——这是装配尺寸，应由结构决定 |
| 螺栓组载荷分配 | 受弯矩/扭矩的螺栓组需按位置分配载荷，是另一层计算 | 另建一份工作流 |
| 疲劳强度校核 | 需要应力幅许用值与螺纹根部应力集中系数 | 相应系数表 |
| 细牙螺纹 | 只录了粗牙系列 | GB/T 193/196 细牙部分 |

### 交叉核对抓到的两处转写错误

建表时的互校不是走形式，真抓到了东西：

1. **M30 的应力截面积**：一处转载记作 `581`，另一处记作 `560.6`。
   定义式 `As = 0.7854(d − 0.9382P)²` 算出 560.6 —— 判为 `561` 的转写错误，未采用。
   差 3.6%，直接用会让 M30 的承载能力被高估。
2. **性能等级表整体错行**：另有一处把 4.8 级的 Rm 记作 500（应为 400），
   显然是抄表时串了行，未采用。


## 常见问题

- **`F0_total` 到底该填什么？** 填螺栓实际承受的**总拉力**。对受轴向工作载荷的
  紧螺栓连接，总拉力 = 残余预紧力 + 工作载荷 × 相对刚度系数 C。
  引擎不替你算这一步，因为缺 C 的表。工程上常取 C = 0.2~0.3（金属垫片），
  但这个数**必须你自己按依据确定**。
- **算出的规格比假定档大/小怎么办？** 按提示改选直径档重算。这不是报错，
  是迭代在正常进行——第二轮通常就收敛了。
- **为什么合金钢选不出来？** 不控制预紧力 + 合金钢这一档表里没有数据。
  改用「控制预紧力」可以算，或者补上那三个值。
- **拧紧力矩为什么给区间？** 见第 5 步的说明。需要精确拧紧力矩的场合
  （钢结构高强度螺栓、密封法兰），必须按工艺试验实测，不能用这个区间下单。
- **8.8 级算碳素钢还是合金钢？** 两者都可能——GB/T 3098.1 允许中碳钢调质
  或合金钢。按你实际采购的材质选，这会影响 S 与预紧力系数。

## 采购关键词模板

螺栓采购关键词顺序：**物料名 → 规格 → 性能等级 → 材料 → 表面处理 → 包装**

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | 固定为 `六角头螺栓`。内六角、法兰面等需自行改 |
| 规格 | **必给** | ✓ `spec` | 只给到 M 号，**长度需人工补**（如 `M16x60`） |
| 性能等级 | **必给** | ✓ `grade` | 如 `8.8级`。缺了会买到 4.8 级 |
| 材料 | 建议 | ✗ 需人工补 | 碳钢 / 304 不锈钢 / 316 不锈钢 |
| 表面处理 | 建议 | ✗ 需人工补 | 发黑 / 镀锌 / 达克罗。注意这会反过来影响 K |
| 包装 | 可选 | ✗ 需人工补 | 如 `50个装` |

> **螺栓长度引擎不算**，因为它取决于被连接件总厚度、垫圈与螺母高度，
> 属于结构尺寸。下单前必须补上，否则卖家无法发货。

**单独生成命令**：

```bash
python scripts/procure_link.py build -m fastener --set kind=六角头螺栓 --set spec=M16x60 --set grade=8.8级 --set surface=达克罗 -c taobao,tmall,jd --format md
```

> **螺栓专属提示**：性能等级标记打在螺栓头上，到货务必核对（8.8 / 10.9 / 12.9）。
> 无标记的多半是等外品。高强度螺栓连接副（螺栓 + 螺母 + 垫圈）应成套采购，
> 混用会破坏扭矩系数的一致性——那正是 K 值离散的主要来源之一。
