# 联轴器（计算转矩与选型校核）工作流

> **本文档与 `coupling.yaml` 的关系**
>
> `coupling.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。

## 基本信息

- 物料类型：联轴器（计算转矩与候选型号校核）
- 依据：GB/T 5014、JB/T 7511 口径的动力机系数；厂商样本的公称转矩 / 孔径 / 许用转速
- 覆盖范围：**计算转矩 Tc 的求取 + 候选型号的四项校核**

## 这是校核，不是型号选择

引擎算出**计算转矩 Tc**，再拿你从**样本**选定的候选型号来校核四项：
公称转矩、许用转速、孔径下限、孔径上限。

**联轴器型式的选择（弹性 / 齿式 / 膜片 / 十字滑块…）引擎不做**——
它取决于对补偿能力、扭转刚度、维护性的取舍，是**设计判断不是计算**。

## 选型目标

确定：理论转矩 T、动力机系数 Kw、计算转矩 Tc、转矩裕度，并校核候选型号的四项参数。

## 输入参数

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 传递功率 | `P` | kW | 0.01 ~ 50000 | |
| 工作转速 | `n` | r/min | 1 ~ 30000 | |
| 动力机类别 | `prime_mover` | — | 枚举 | 选项读自 `condition_factors.prime_movers` |
| 工作机工况系数 | `K_work` | — | 1.0 ~ 5.0 | 默认 1.5。**按你所选样本的工况系数表取** |
| 候选型号的公称转矩 Tn | `Tn_catalog` | N·m | 0.1 ~ 10⁷ | 从样本抄 |
| 候选型号的许用转速 | `n_allow_catalog` | r/min | 1 ~ 100000 | 从样本抄 |
| 轴径 | `d_shaft` | mm | 5 ~ 1000 | 两端轴径不同时分别校核 |
| 候选型号的最小孔径 | `bore_min_catalog` | mm | 1 ~ 1000 | 从样本抄 |
| 候选型号的最大孔径 | `bore_max_catalog` | mm | 1 ~ 1000 | 从样本抄 |

## 计算步骤

共 **9 个 step**。

### 第 1 步：计算转矩

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `T` | 公式 | **T = 9550 P / n**（N·m） |
| `prime_mover_label` | 查表 | 动力机类别的中文名，供结果表显示 |
| `Kw` | 查表 | `prime_movers.{prime_mover}.Kw` |
| `Tc` | 公式 | **Tc = Kw · K工作机 · T**（N·m） |

| 动力机类别 | Kw |
|---|---|
| **I 类 —— 电动机、汽轮机** | **1.0** |
| II 类 —— 四缸及以上内燃机 | 1.2 |
| III 类 —— 双缸内燃机 | 1.4 |
| IV 类 —— 单缸内燃机 | 1.6 |

> **两个系数分工不同，别混为一谈：**
> - `Kw` —— 动力机系数，反映**驱动端**的转矩波动（缸数越少波动越大）
> - `K_work` —— 工况系数，反映**负载端**的冲击、正反转、制动、频繁启动
>
> 只有 Kw 有可核对的出处，录在表里。**K_work 改为用户输入**——
> 各厂商样本与 JB/T 7511 的口径不完全一致，用哪张表应当跟着你选的那个样本走。

### 第 2 步：四项校核

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `chk_torque` | 校核 | Tn ≥ Tc |
| `chk_speed` | 校核 | n ≤ 许用转速 |
| `chk_bore_lo` | 校核 | 轴径 ≥ 最小孔径 |
| `chk_bore_hi` | 校核 | 轴径 ≤ 最大孔径 |

> **四项一个都不能少。** 少一项就等于替用户放行了一个他没查的条件。
> 有一条测试专门断言这四项都在。

### 第 3 步：裕度

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `margin` | 公式 | **Tn / Tc** |

> 裕度**过大也是问题**：联轴器的转动惯量会拖累系统的动态响应，
> 而且白白增加成本与安装空间。过小则没有余地。

## 校核条件

引擎实际执行的 **4 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_torque` | 公称转矩 | Tn ≥ Tc | 改选更大规格；或核对工况系数是否取得过于保守 |
| `chk_speed` | 许用转速 | n ≤ 许用转速 | 改选高速型（膜片、弹性柱销）或平衡等级更高的规格 |
| `chk_bore_lo` | 轴径下限 | 轴径 ≥ 最小孔径 | 改选更小规格 |
| `chk_bore_hi` | 轴径上限 | 轴径 ≤ 最大孔径 | 改选更大规格 |

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| **工作机工况系数表** | 各厂商样本与 JB/T 7511 口径不一致 | 你所选样本的那张表 |
| **起动系数 Ks、温度系数 Kt** | 检索不到可核对的数值 | JB/T 7511 或样本原表。频繁启动 / 高低温工况需自行追加 |
| **型号库** | 每型号一行的厂商数据，自建会给出错的数 | ——**刻意不做** |
| 联轴器型式的选择 | 取决于补偿能力、扭转刚度、维护性的取舍，是设计判断 | ——**刻意不做** |
| 两端轴径不同时的分别校核 | v1 只收一个轴径 | 改成两组输入即可，但会让表单变复杂 |
| 许用补偿量校核（径向/角向/轴向偏移） | 每型号一组样本数据 | 样本 |

## 已验证算例

输入：7.5 kW / 1450 r/min，电动机驱动，K工作机 = 1.5，
候选型号 Tn = 250 N·m、许用转速 4000 r/min、孔径 30~55 mm，轴径 42 mm。

| 步骤 | 结果 |
|---|---|
| 理论转矩 T | 49.3966 N·m |
| 动力机系数 Kw | 1.0 |
| **计算转矩 Tc** | **74.0948 N·m** |
| 转矩裕度 | 3.3741 |
| 校核 | **4 / 4 通过** |

> 裕度 3.37 偏大——250 N·m 的型号对 74 N·m 的需求是选大了。
> 实际选型时可以往下试一档，但要注意孔径范围是否还容得下 φ42 的轴：
> **联轴器常常是孔径而不是转矩定规格的。**

```bash
python -m mds run coupling -s P=7.5 -s n=1450 -s prime_mover=class_1 -s K_work=1.5 -s Tn_catalog=250 -s n_allow_catalog=4000 -s d_shaft=42 -s bore_min_catalog=30 -s bore_max_catalog=55
```

## 常见问题

- **K_work 填多少？** 查你所选厂商样本里的工况系数表。
  典型范围 1.0（平稳）~ 4.0（严重冲击、频繁正反转）。**引擎不给默认依据**，
  默认值 1.5 只是个占位，必须按样本改。
- **为什么不帮我选型号？** 型号表是每型号一行的厂商数据，成千上万条且各家不同。
  引擎替你算 Tc 并校核你选的型号，这是它能可靠做的部分。
- **裕度多大合适？** 没有统一答案。裕度过大意味着转动惯量、成本与安装空间都白费；
  过小则没有余地。多数场合 1.2~2 是合理区间，但要按具体工况判断。
- **两端轴径不一样怎么办？** 分别跑两次，各用各的轴径。
  v1 只收一个轴径是为了让表单简单。
- **转速高要注意什么？** 除了许用转速，还要看**动平衡等级**。
  高速场合选膜片或弹性柱销型，并要求厂商提供动平衡报告。

## 采购关键词模板

联轴器走 `coupling` 模板：

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | `联轴器`。需要写清型式，如 `弹性柱销联轴器` |
| 孔径 | **必给** | ✓ `spec` | 两端孔径都要给，如 `孔径42-38` |
| 型号 | **必给** | ✗ 需人工补 | 如 `LX4`、`ML5`。**这是最关键的一项** |
| 材质 | 建议 | ✗ 需人工补 | 45钢 / 铸铁 / 铝合金 |
| 键槽 | 建议 | ✗ 需人工补 | 是否需要预加工键槽，按 GB/T 1095 |

```bash
python scripts/procure_link.py build -m coupling --set kind=弹性柱销联轴器 --set model=LX4 --set spec="孔径42-38" -c taobao,1688 --format md
```

> **联轴器专属提示**：下单必须同时给**两端孔径**与**键槽尺寸**，
> 只给型号卖家无法发货——同一型号可以配很多种孔径。
> 弹性件（柱销、梅花垫、膜片）是**易损件**，建议同时备一套。
