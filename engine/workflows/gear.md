# 渐开线圆柱齿轮（几何计算与接触应力核算）工作流

> **本文档与 `gear.yaml` 的关系**
>
> `gear.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。

> ## ⚠ 这不是完整的 GB/T 3480 承载能力计算
>
> 标准里 **ZH（节点区域系数）、YFa / YSa（齿形与应力修正系数）、σHlim（材料疲劳极限）
> 都是线图**，读不出可核对的数值。
>
> 所以本工作流的边界是：
>
> | | 做不做 |
> |---|---|
> | 几何计算（分度圆、齿顶圆、齿根圆、中心距、重合度、变位） | ✅ **全做**，全是定义式 |
> | 接触应力 σH | ⚠ 公式确定，但 **ZH 与许用应力由你按线图查好后填入** |
> | 弯曲强度校核 | ❌ **完全不做** |
>
> **宁可说清边界，也不要让人以为软件替他做了强度校核。**

## 基本信息

- 物料类型：**外啮合渐开线圆柱齿轮**（直齿与斜齿）
- 主导标准：**GB/T 1356**（标准基本齿条齿廓）、**GB/T 3480**（承载能力计算方法）
- 覆盖范围：法向模数 0.1 ~ 50 mm，螺旋角 0° ~ 45°，变位系数 −1 ~ +1

**不覆盖**：内啮合、锥齿轮、蜗轮蜗杆、人字齿；弹性系数只有钢-钢配对。

## 选型目标

确定：齿数比、分度圆 / 齿顶圆 / 齿根圆直径、中心距、齿宽、端面重合度、
计算接触应力，并与许用接触应力比较。

## 输入参数

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 法向模数 | `m_n` | mm | 0.1 ~ 50 | 默认 2。**从 GB/T 1357 系列自行取值，引擎不做圆整** |
| 小齿轮齿数 | `z1` | — | 6 ~ 400 | 默认 20 |
| 大齿轮齿数 | `z2` | — | 6 ~ 2000 | 默认 60 |
| 螺旋角 | `beta` | 度 | 0 ~ 45 | 直齿填 0。斜齿常用 8°~20° |
| 小齿轮变位系数 | `x1` | — | −1 ~ 1 | 默认 0 |
| 大齿轮变位系数 | `x2` | — | −1 ~ 1 | 默认 0 |
| 齿宽系数 ψd | `psi_d` | — | 0.1 ~ 2.0 | 默认 1.0。b = ψd × d1 |
| 小齿轮转矩 | `T1` | N·m | 0.01 ~ 10⁶ | |
| 配对材料 | `material_pair` | — | 枚举 | 只有 `steel_steel` |
| 节点区域系数 ZH | `ZH` | — | 1.5 ~ 3.5 | **按 GB/T 3480 图 3 查取**。标准直齿约 2.5 |
| 载荷系数 K | `K` | — | 1.0 ~ 5.0 | **KA·KV·KHβ·KHα 之积**。一般机械 1.3~2.0 |
| 许用接触应力 | `sigma_HP` | MPa | 100 ~ 2000 | **按 GB/T 3480 线图查取** |

> **为什么 K 合并成一个？** 使用系数 KA、动载系数 KV、齿向载荷分布系数 KHβ、
> 齿间载荷分配系数 KHα ——**四张表一张都没有**。分开填只是把同一个不确定性
> 拆成四份，不会更准，只会让人误以为做得更细。

## 计算步骤

共 **17 个 step**。

### 第 1 步：基本齿廓参数

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `ha_star` | 查表 | 齿顶高系数 = 1.0 |
| `c_star` | 查表 | 顶隙系数 = 0.25 |
| `alpha_n` | 查表 | 法向压力角 = 20° |

> 这三个是 **GB/T 1356 标准基本齿条齿廓的定义值**。非标齿廓不适用本工作流。

### 第 2 步：几何（全是定义式）

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `u` | 公式 | **u = z2 / z1** |
| `d1` / `d2` | 公式 | **d = mn·z / cos β**（mm） |
| `a` | 公式 | **a = mn(z1+z2) / (2 cos β)**（mm） |
| `da1` / `da2` | 公式 | **da = d + 2mn(ha\* + x)**（mm） |
| `df1` / `df2` | 公式 | **df = d − 2mn(ha\* + c\* − x)**（mm） |
| `b` | 公式 | **b = ψd · d1**（mm） |

> **斜齿的分度圆按端面模数算**：mt = mn / cos β。
> 忘了除 cos β 会把中心距算小，装配时对不上——测试专门守这一条。

> 齿宽按**小齿轮**分度圆定。实际大齿轮常比小齿轮窄 5~10 mm 以补偿装配误差，
> 这一步引擎不做。

### 第 3 步：重合度（仅标准齿轮）

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `eps_alpha` | 公式 | 仅 `x1 == 0 and x2 == 0`；**εα = [z1(tan αa1 − tan α) + z2(tan αa2 − tan α)] / 2π** |
| `chk_eps` | 校核 | 仅标准齿轮；εα ≥ 1.2 |

> **变位齿轮的重合度不算。** 要先解啮合角 α'，那是个超越方程，v1 未实现。
> 不做就要明确跳过（标 `not_applicable`），**不能拿标准齿轮的公式硬算一个错的数**。

### 第 4 步：接触应力

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `ZE` | 查表 | `elastic_factor.{material_pair}.ZE` = 189.8 √MPa（钢-钢） |
| `sigma_H` | 公式 | **σH = ZE·ZH·√(2KT1/(b·d1²) · (u+1)/u)**（MPa） |
| `chk_contact` | 校核 | σH ≤ 许用接触应力 |

> σH ∝ **√T**。翻四倍转矩，应力只翻一倍——这就是为什么齿轮超载时
> 往往先出现点蚀而不是立刻断齿。

## 校核条件

引擎实际执行的 **2 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 | 适用分支 |
|---|---|---|---|---|
| `chk_eps` | 重合度 | εα ≥ 1.2 | 增大齿数、减小压力角或改用斜齿 | 仅标准齿轮 |
| `chk_contact` | 接触强度 | σH ≤ 许用接触应力 | 增大模数或齿宽、提高齿面硬度、增大中心距，或改斜齿 | 全部 |

> **弯曲强度校核完全不做**（缺 YFa / YSa / σFlim）。
> 有测试断言校核项里不出现"弯曲"二字——
> 这是最容易被后来人"顺手补全"的地方。

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| **弯曲强度校核** | YFa、YSa、σFlim 都是线图 | 线图数字化 |
| **ZH 自动查取** | GB/T 3480 图 3 是线图 | 同上。目前由用户填 |
| **σHlim / 许用应力自动查取** | 线图 | 同上。目前由用户填 |
| **KA / KV / KHβ / KHα 分项** | 四张表都没有 | 四张表。目前合并为一个 K |
| 模数圆整 | GB/T 1357 模数系列检索不到可核对数值 | 系列表 |
| 变位齿轮的重合度与实际中心距 | 要解啮合角 α'（超越方程） | 数值求解 + 变位齿轮公式 |
| 非钢-钢配对的 ZE | 只录了钢-钢 | 其它配对的弹性模量与泊松比 |
| 内啮合、锥齿轮、蜗轮蜗杆、人字齿 | 各有各的几何与强度算法 | 各建一份工作流 |

## 已验证算例

输入：mn = 2 mm，z1 = 20，z2 = 60，直齿不变位，ψd = 1.0，T1 = 100 N·m，
钢-钢，ZH = 2.5，K = 1.5，许用接触应力 600 MPa。

| 步骤 | 结果 |
|---|---|
| 齿数比 u | 3 |
| 分度圆 d1 / d2 | 40 / 120 mm |
| 中心距 a | 80 mm |
| 齿顶圆 da1 / da2 | 44 / 124 mm |
| 齿根圆 df1 / df2 | 35 / 115 mm |
| 齿宽 b | 40 mm |
| 端面重合度 εα | **1.6708** ≥ 1.2 ✓ |
| 弹性系数 ZE | 189.8 |
| **计算接触应力 σH** | **1186.25 MPa** |
| 许用接触应力 | 600 MPa |
| 校核 | ❌ **接触强度不通过** |

> 这是个**刻意选的不通过算例**：φ40 的小齿轮传 100 N·m 显然偏小。
> 按 σH ∝ 1/d1·√(1/b) 的关系，要降到 600 MPa 需要把 d1 与 b 各放大约一倍——
> 也就是模数取 4。算例演示的正是这个量级感。

```bash
python -m mds run gear -s m_n=2 -s z1=20 -s z2=60 -s beta=0 -s x1=0 -s x2=0 -s psi_d=1.0 -s T1=100 -s material_pair=steel_steel -s ZH=2.5 -s K=1.5 -s sigma_HP=600
```

## 常见问题

- **ZH 填多少？** 查 GB/T 3480 的图 3，按 (x1+x2)/(z1+z2) 与螺旋角 β。
  标准直齿（x1+x2 = 0、β = 0）约 **2.5**。默认值就是这个，但变位或斜齿必须重查。
- **许用接触应力从哪来？** σHlim 查材料线图，再除以安全系数 SH，
  并计入寿命系数 ZN、润滑系数 ZL 等修正。**引擎不做这一串**，你算好了填进来。
- **K 填多少？** 一般机械 1.3~2.0；有冲击、高速或悬臂布置取大值。
  这是四个分系数的乘积，拿不准就往大取。
- **为什么不算弯曲强度？** 缺 YFa、YSa、σFlim，都是线图。
  **接触强度通过不代表弯曲强度通过**——小模数、大齿宽的设计往往是弯曲控制的，
  必须另行校核。
- **为什么模数不圆整？** GB/T 1357 的模数系列检索不到可核对的数值。
  请自行从标准系列（1、1.25、1.5、2、2.5、3、4、5、6、8、10…）里取。
- **变位齿轮为什么不算重合度？** 要先解啮合角 α'，是超越方程。
  引擎明确跳过并标注"本条工况分支用不到这一步"，而不是拿标准公式硬算。

## 采购关键词模板

齿轮走 `gear` 模板：

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | `圆柱齿轮`。斜齿要写明 |
| 模数 + 齿数 | **必给** | ✓ `spec` | 如 `模数2 齿数20` |
| 压力角 | **必给** | ✓（在关键字里） | 标准件是 20°，非标要写明 |
| 材料与热处理 | 建议 | ✗ 需人工补 | 45钢调质 / 20CrMnTi 渗碳淬火 |
| 精度等级 | 建议 | ✗ 需人工补 | GB/T 10095 的 7 / 8 / 9 级 |
| 齿宽与孔径 | **必给** | ✗ 需人工补 | 货架齿轮的齿宽是固定的，要核对 |

```bash
python scripts/procure_link.py build -m gear --set kind=圆柱齿轮 --set spec="模数2 齿数20" --set material=45钢调质 --set grade=8级 -c taobao,1688 --format md
```

> **齿轮专属提示**：货架齿轮的**齿宽与孔径是固定的**，不一定等于你算出来的 b，
> 下单前务必核对。要求齿宽、孔径、键槽都按图的，只能定制。
> 另外**模数 + 齿数 + 压力角三者必须同时给**——只说"20 齿齿轮"卖家无法发货。
