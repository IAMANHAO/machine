# O 形密封圈（压缩率与材料适用性）工作流

> **本文档与 `seal.yaml` 的关系**
>
> `seal.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。

## 基本信息

- 物料类型：**O 形橡胶密封圈**
- 主导标准：
  - **GB/T 3452.1-2005**《液压气动用O形橡胶密封圈 第1部分：尺寸系列及公差》
  - **GB/T 3452.3-2005**《…沟槽尺寸》
  - **GB/T 3452.5-2022**《…弹性体材料规范》
- 覆盖范围：截面直径 **1.8 / 2.65 / 3.55 / 5.3 / 7.0 mm** 五档；NBR / FKM / EPDM / VMQ 四种材料

**不覆盖**：油封、Y 形圈、格莱圈、机械密封。

## 只报数，不判定

**压缩率与填充率的合格判据在 GB/T 3452.3 里，缓存中没有。**

引擎把算出来的数交给你，判定请对照标准原文或厂商设计手册。
凭印象设一个阈值，等于编了一条判据。

同样地，**介质相容性只给定性的适用/回避说明，不做自动判定**——
相容性表是按具体介质逐条列的，缓存里没有。

## 选型目标

确定：标准截面直径、O 圈规格标注、压缩率、沟槽填充率，
并校核材料的温度适用性。

## 输入参数

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| O 圈截面直径 | `d2_in` | mm | 1.8 ~ 7.0 | 默认 2.65。会自动取最接近的标准值 |
| O 圈内径 | `d1` | mm | 1 ~ 2000 | 与 d2 一起构成规格（d1 × d2） |
| 沟槽深度 h | `groove_depth` | mm | 0.5 ~ 10 | **从 GB/T 3452.3 或你的图纸填** |
| 沟槽宽度 b | `groove_width` | mm | 0.5 ~ 20 | 同上 |
| 材料 | `material` | — | 枚举 | 选项读自 `oring.materials` |
| 工作温度 | `T_work` | ℃ | −100 ~ 400 | 密封处的实际温度，不是环境温度 |

## 计算步骤

共 **13 个 step**。

### 第 1 步：截面直径取标准值与标注

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `d2` | 圆整 | 取 `section_series.series` 里最接近的标准值 |
| `spec_label` | 文本 | `40×2.65` —— 内径 × 截面直径 |
| `material_label` | 查表 | 材料中文名 |
| `material_code` | 文本 | 材料代号，供采购关键词用 |

> **用圆整而不是下拉框**，是为了让「你填的 2.7 被取成 2.65」这件事
> **出现在计算过程里**，而不是悄悄发生在界面上。
> 计算卡片会显示 `2.7 → 2.65`。

### 第 2 步：压缩率与填充率

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `compression` | 公式 | **压缩率 = (d2 − h) / d2 × 100%** |
| `fill_ratio` | 公式 | **填充率 = (π d2²/4) / (h · b) × 100%** |
| `chk_compression_positive` | 校核 | 压缩率 > 0 |

> 填充率过高时，O 圈受热膨胀无处可去，会被挤出沟槽失效。
> **但合格上限在 GB/T 3452.3 里，引擎不判定。**
>
> `chk_compression_positive` 守的只是一条**结构性底线**：
> 沟槽深度不小于截面直径，O 圈根本没被压缩，那就不是密封了。

### 第 3 步：材料温度适用性

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `temp_min` / `temp_max` | 查表 | 该材料的适用温度上下限 |
| `media` | 查表 | 适用介质（定性说明） |
| `avoid` | 查表 | 应避免的介质（定性说明） |
| `chk_temp_hi` | 校核 | T ≤ 上限 |
| `chk_temp_lo` | 校核 | T ≥ 下限 |

| 材料 | 温度范围 | 适用 | 回避 |
|---|---|---|---|
| **NBR 丁腈（最常用）** | **−25 ~ 100 ℃** | 液压油、矿物油、水 | 极性溶剂、酮酯类、磷酸酯液压液 |
| FKM 氟橡胶 | −20 ~ 250 ℃ | 大部分油与溶剂、酸、燃油 | 低温、酮胺类、热水蒸汽 |
| EPDM 三元乙丙 | −50 ~ 150 ℃ | 水、水蒸汽、制动液、磷酸酯 | **矿物油与润滑脂（会溶胀）** |
| VMQ 硅橡胶 | −60 ~ 200 ℃ | 静密封、宽温域、食品医药 | 动密封（耐磨差）、水蒸汽、高压 |

> **温度范围取的是两处信源的保守交集。** 差异很大：
> NBR 甲给 −55~150、乙给 −25~100；FKM 甲给 −44~275、乙给 −20~250。
> 各自原值记在 `oring.yaml` 的 `_todo` 里。
>
> 差异多半源于「通用牌号」与「特定配方」的口径不同，
> **正式选用必须按厂商 PDS。** 取宽的那个会让人以为 NBR 能用到 150 ℃。

## 校核条件

引擎实际执行的 **3 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_compression_positive` | 压缩率有效性 | 压缩率 > 0 | 沟槽深度不小于截面直径，核对沟槽尺寸 |
| `chk_temp_hi` | 温度上限 | T ≤ 材料上限 | 改用耐温更高的材料（FKM 或 VMQ） |
| `chk_temp_lo` | 温度下限 | T ≥ 材料下限 | 改用耐寒材料（VMQ 或 EPDM） |

## 常见问题

- **压缩率多少合适？** 查 GB/T 3452.3。**引擎不给这个判据**——
  静密封与动密封、径向与轴向的推荐值都不同，凭印象设一个阈值是在编判据。
- **填充率为什么不能太高？** O 圈受热会膨胀，沟槽必须留出膨胀空间，
  否则会被挤出间隙（extrusion）而失效。
- **NBR 能用到 120 ℃ 吗？** 本表按保守口径给到 100 ℃。
  有些厂商的特定配方能更高——**以你采购的那个牌号的 PDS 为准**。
- **EPDM 为什么不能碰矿物油？** 会溶胀，尺寸和硬度都会变。
  但它耐水、耐水蒸汽、耐磷酸酯液压液——**选材要看介质，不只看温度**。
- **高压场合要注意什么？** 需要加**挡圈**防止挤出。判据是压力与配合间隙的组合，
  引擎不做，请查标准或厂商手册。

## 采购关键词模板

密封件走 `seal` 模板：

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | `O形圈` |
| 规格 | **必给** | ✓ `spec` | `内径×截面直径`，如 `40×2.65` |
| 材料 | **必给** | ✗ 需人工补 | NBR / FKM / EPDM / VMQ。**关键词里最好写中文** |
| 硬度 | 建议 | ✗ 需人工补 | 邵氏 A 70 是通用值，高压用 90 |
| 颜色 | 参考 | ✗ | 黑=NBR、棕/绿=FKM、红/橙=硅胶，但**不同厂商不统一，别靠颜色认材料** |

```bash
python scripts/procure_link.py build -m seal --set kind=O形圈 --set spec="40x2.65" --set material=氟橡胶FKM --set grade=邵氏70 -c taobao,1688 --format md
```

> **密封件专属提示**：O 圈按 `内径 × 线径` 下单，两个数缺一不可。
> **不要靠颜色判断材料**——各厂商的配色不统一，黑色的可能是 NBR 也可能是 EPDM，
> 装错了遇到矿物油会直接溶胀报废。要求供方提供材质证明。
