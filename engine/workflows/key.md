# 普通平键（静连接）选型工作流

> **本文档与 `key.yaml` 的关系**
>
> `key.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。改公式先改 YAML，再回填本文档。

## 基本信息

- 物料类型：普通平键连接（**静连接**）
- 主导标准：
  - **GB/T 1095-2003**《平键 键槽的剖面尺寸》
  - **GB/T 1096-2003**《普通型 平键》
- 主要信源：上述标准经嘉立创FA 机械设计手册在线版转载；许用应力取机械设计手册表 6-3-17 口径
- 覆盖范围：**轴径 6 ~ 500 mm**，键宽 b = 2 ~ 100 mm，A / B / C 三种键型

**不覆盖**：导向平键与滑键（动连接）、半圆键、楔键、切向键、花键。原因见「未实现项」。

## 选型目标

确定：键的截面尺寸 b×h、标准键长 L、工作长度 l、轴槽深 t1、毂槽深 t2，
并校核挤压强度。

## 输入参数

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 轴的公称直径 | `d` | mm | 6 ~ 500 | 决定键的截面尺寸 b×h |
| 传递转矩 | `T` | N·m | 0.1 ~ 1000000 | 由功率换算：T = 9550 P / n |
| 轮毂长度 | `L_hub` | mm | 8 ~ 600 | 键长取不大于此值的最大标准值 |
| 键型 | `key_type` | — | `A` / `B` / `C` | 默认 A 型（圆头） |
| 最弱件材料 | `weak_material` | — | `steel` / `cast_iron` | **取键、轴、轮毂三者中最弱的那一个** |
| 载荷性质 | `load_type` | — | `static` / `light_impact` / `impact` | 默认轻微冲击 |

> **`weak_material` 是这个工作流里最容易选错、后果最严重的一项。**
>
> 键、轴、轮毂三者材料可能不同，许用应力必须取**最弱**的那个。
> 典型场合是钢轴 + 铸铁齿轮：按铸铁查是 50~60 MPa，按钢查是 100~120 MPa，**差一倍**。
> 选错这一项，校核会轻松通过，而实际轮毂会被压溃。
>
> 引擎不替你判断三者中谁最弱——它不知道你的轮毂是什么材料。

> **输入域就是数据覆盖范围。** GB/T 1095 只覆盖轴径 6~500，所以 `d` 的域也是 6~500。
> 填 φ520 会在**进门时**被挡下并说清是哪一项超限，而不是一路算到查表才报缺数据——
> 报错离用户能改的那个输入框更近。

## 计算步骤

共 **10 个 step**。每行的「步骤 id」即 YAML 里的 `- id:`。

### 第 1 步：按轴径查截面尺寸

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `section` | **选行** | 在 `keyway_dimensions.by_shaft_diameter` 里取满足 `d_from < d ≤ d_to` 的行，取回 `b` / `h` / `t1` / `t2` |

> **区间是左开右闭。** 标准写作「>30~38」，即 `d_from < d ≤ d_to`，
> 边界值归上一行：d = 30 取 8×7，不是 10×8。`row_select` 的两个条件就是照这个写的。

| 轴径 d | b×h | t1 | t2 |
|---|---|---|---|
| >22~30 | 8×7 | 4.0 | 3.3 |
| >30~38 | 10×8 | 5.0 | 3.3 |
| >38~44 | 12×8 | 5.0 | 3.3 |
| **>44~50** | **14×9** | **5.5** | **3.8** |
| >50~58 | 16×10 | 6.0 | 4.3 |
| >58~65 | 18×11 | 7.0 | 4.4 |
| …完整 26 行见 `keyway_dimensions.yaml` | | | |

> `t1 + t2 > h` —— 轴槽与毂槽之间留有间隙。**平键靠侧面传力，顶面不接触**，
> 所以强度校核算的是侧面挤压，接触高度取 h/2。

### 第 2 步：定键长与工作长度

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `L` | 圆整 | 向下取 `length_series` 里不大于 `L_hub` 的最大标准键长 |
| `l_work_A` | 公式 | 仅 A 型：**l = L − b** |
| `l_work_B` | 公式 | 仅 B 型：**l = L** |
| `l_work_C` | 公式 | 仅 C 型：**l = L − b/2** |
| `chk_l_positive` | 校核 | l > 0 |

标准键长系列（GB/T 1096）：
10, 12, 14, 16, 18, 20, 22, 25, 28, 32, 36, 40, 45, 50, 56, 63, 70, 80, 90,
100, 110, 125, 140, 160, 180, 200, 220, 250, 280, 320, 360, 400

> 键长取**不大于轮毂长度**的最大标准值——比轮毂长的键装不进去。

### 第 3 步：挤压强度校核

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `sigma_p` | 公式 | **σp = 2T/(d·k·l) = 4T/(d·h·l)**（MPa，k = h/2） |
| `sigma_p_allow` | 查表 | `allowable_stress.static_connection.{weak_material}.{load_type}.min` |
| `chk_sigma_p` | 校核 | σp ≤ [σp]，不通过 → 加长轮毂、用双键（相隔 180°，按 1.5 倍承载计）、或改花键 |

| 载荷性质 | 钢 | 铸铁 |
|---|---|---|
| 静载荷 | 125 ~ 150 | 70 ~ 80 |
| **轻微冲击** | **100 ~ 120** | **50 ~ 60** |
| 冲击载荷 | 60 ~ 90 | 30 ~ 45 |

> **每格给的是区间，本工作流一律取下端**（偏安全）。
> 需要用上端的场合（载荷十分平稳、材料性能有保证），应由设计者自行判断并记录依据，
> 而不是让软件默认给你一个宽松值。

### 第 4 步：规格标注

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `spec_label` | 文本 | `A 型 14×9×70`，GB/T 1096 的标记方式 |

## 校核条件

引擎实际执行的 **2 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_l_positive` | 工作长度有效性 | l > 0 | 键长小于键宽说明轮毂太短，需加长轮毂或改花键 |
| `chk_sigma_p` | 挤压强度 | σp ≤ [σp] | 加长轮毂以加长键、改用双键、或改用花键 |

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| **剪切强度校核** | 缓存里没有许用切应力 `[τ]` 的表 | 一张 [τ] 表。注：普通平键的主要失效形式是较弱工作面被压溃，工程上通常只校核挤压——**但这是惯例不是免检**，重载冲击场合应另行校核 |
| 动连接（导向平键 / 滑键） | 用的是许用压强 `[p]`，与静连接是两套口径，而且还要校核磨损 | [p] 表 + 磨损校核方法。`allowable_stress.yaml` 里存了 [p] 的参考值但未接入 |
| 双键的承载折算 | 「相隔 180° 按 1.5 倍计」是经验做法，折算系数没有可追溯的依据 | 手册出处 |
| 公差带与粗糙度 | 只录了尺寸与槽深 | GB/T 1095 的公差带部分（较松 H9/D10、一般 N9/Js9、较紧 P9/P9） |
| 半圆键 / 楔键 / 切向键 / 花键 | 各有各的标准与算法 | 各建一份工作流 |

## 已验证算例

输入：φ45 轴，传递 300 N·m，轮毂长 70 mm，A 型键，**铸铁**轮毂，轻微冲击。

| 步骤 | 结果 |
|---|---|
| 截面 b×h | 14×9 mm |
| t1 / t2 | 5.5 / 3.8 mm |
| 标准键长 L | 70 mm |
| 工作长度 l | 56 mm（= 70 − 14） |
| σp | 52.9101 MPa |
| [σp] | 50 MPa（铸铁 · 轻微冲击） |
| 校核 | **❌ 挤压强度不通过**（52.91 > 50） |

> 这是个**刻意选的临界算例**：同样的几何、同样的转矩，
> 轮毂换成钢（[σp] = 100）就通过了。它演示的正是 `weak_material` 选错的后果。

```bash
python -m mds run key -s d=45 -s T=300 -s L_hub=70 -s key_type=A -s weak_material=cast_iron -s load_type=light_impact
```

## 常见问题

- **转矩 T 怎么来？** T(N·m) = 9550 × P(kW) / n(r/min)。引擎不做这一步，
  因为轴上的转矩未必等于电机输出转矩（要考虑传动比与效率）。
- **A / B / C 型怎么选？** A 型（圆头）最常用，键槽用指状铣刀铣，键在槽中不会轴向窜动；
  B 型（方头）键槽用盘铣刀铣，加工方便但应力集中略大；C 型（单圆头）用于轴端。
- **校核不通过怎么办？** 按提示：加长轮毂以加长键 → 改用双键（相隔 180°，
  工程上按 1.5 倍承载计，注意这个系数**引擎没有实现**）→ 改用花键。
- **为什么不校核剪切？** 见「未实现项」。缺 [τ] 表，引擎不编。
- **键长能等于轮毂长度吗？** 可以，算例里就是（L_hub = 70 恰好是标准值）。
  实际装配常取略短于轮毂，本工作流取「不大于轮毂长度的最大标准值」。

## 采购关键词模板

平键走 `generic` 模板：**物料名 → 规格 → 材质**

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | 固定为 `普通平键` |
| 规格 | **必给** | ✓ `spec` | 如 `A 型 14×9×70`，三要素缺一不可 |
| 材质 | 建议 | ✓ `grade` | 默认 `45钢`。不锈钢场合需自行改 |

```bash
python scripts/procure_link.py build -m generic --set kind=普通平键 --set spec="A型 14x9x70" --set grade=45钢 -c taobao,tmall,jd --format md
```

> **平键专属提示**：键是标准件，按 `b×h×L` 三要素下单即可，单价很低。
> 但**键槽要自己加工**——买键之前先确认轴和轮毂的槽已按 GB/T 1095 的公差带铣好，
> 配合选错（较松 / 一般 / 较紧）会导致装不进或松动。
