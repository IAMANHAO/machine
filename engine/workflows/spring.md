# 圆柱螺旋压缩弹簧 选型校核工作流

> **本文档与 `spring.yaml` 的关系**
>
> `spring.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。改公式先改 YAML，再回填本文档。

## 基本信息

- 物料类型：圆柱螺旋**压缩**弹簧，**圆截面**钢丝
- 依据：GB/T 1239.2《冷卷圆柱螺旋弹簧技术条件 压缩弹簧》、GB/T 2089《圆柱螺旋压缩弹簧 尺寸及参数》
- 主要信源：公开设计资料（稳定性临界值、载荷类别划分）
- 覆盖范围：钢丝直径 0.2 ~ 60 mm，旋绕比 C = 4 ~ 16

**不覆盖**：拉伸弹簧、扭转弹簧、变节距/圆锥弹簧、矩形截面丝、疲劳寿命校核。

## 这个物料最能说明「数据拿不到时该怎么办」

三样东西检索不到可核对的出处：**弹簧钢丝直径系列（GB/T 1358）**、
**切变模量 G**、**I 类与 II 类的许用切应力比**。

处理方式不是编，而是**改变分工**：

| 拿不到的 | 怎么办 |
|---|---|
| 钢丝直径系列 | 由用户填实际能采购到的直径，引擎算出所需最小值并**校核** |
| 切变模量 G | 改为**必填输入**，从材料证书上抄 |
| I / II 类系数 | 表里**留空**，选到就报缺口；另给一条「手工指定 [τ]」的通路 |

结果是这个工作流**「算」的部分很扎实**（曲度系数、强度、刚度、圈数全是定义式），
**「查」的部分极少**（只有稳定性临界值和 III 类的一个系数）。
这是数据现状决定的，不是设计取巧。

## 选型目标

确定：曲度系数 K、许用切应力 [τ]、所需最小钢丝直径、弹簧中径 D2 与外径 D、
有效圈数 n、弹簧刚度 k、最大工作变形与工作切应力，并校核强度与稳定性。

## 输入参数

### 必填

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 最大工作载荷 | `F_max` | N | 0.1 ~ 1000000 | |
| 最小工作载荷 | `F_min` | N | 0 ~ 1000000 | 预压载荷，无预压填 0 |
| 工作行程 | `stroke` | mm | 0.1 ~ 2000 | 最小到最大载荷之间的压缩量变化 |
| 钢丝直径 | `d` | mm | 0.2 ~ 60 | **填实际可采购的**；引擎校核够不够 |
| 旋绕比 | `C` | — | 4 ~ 16 | 默认 6。常用 5~8 |
| 材料切变模量 | `G` | MPa | 30000 ~ 100000 | **从材料证书或厂商样本查取** |
| 弹簧自由高度 | `H0` | mm | 1 ~ 3000 | 通常由安装空间先定，引擎用它校核稳定性 |
| 端部约束型式 | `end_support` | — | 枚举 | 默认两端回转。选项读自 `stability_limits` |
| 许用切应力来源 | `tau_source` | — | `from_class` / `manual` | 默认按载荷类别算 |

### 分支必填

| 参数 | id | 单位 | 域 | 何时必填 |
|---|---|---|---|---|
| 载荷类别 | `load_class` | — | `class_1` / `class_2` / `class_3` | `tau_source == 'from_class'` |
| 钢丝抗拉强度 σb | `sigma_b` | MPa | 300 ~ 3000 | `tau_source == 'from_class'` |
| 许用切应力 | `tau_in` | MPa | 50 ~ 1500 | `tau_source == 'manual'` |

> **旋绕比 C 的边界不是数据，是工程约束。** C 过小卷绕困难且簧丝内侧应力集中大，
> C 过大弹簧过软、易颤动。4~16 是通行的可制造范围。

> **自由高度 H0 是输入不是输出。** 完整算 H0 需要节距、支承圈型式与并紧磨平量，
> 那几个系数缓存里没有。实际设计中 H0 通常由安装空间先定下来，所以收它作输入。

## 计算步骤

共 **17 个 step**。每行的「步骤 id」即 YAML 里的 `- id:`。

### 第 1 步：许用切应力

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `tau_ratio` | 查表 | 仅 `from_class`；取 `ratio_by_class.{load_class}.tau_ratio` |
| `tau_from_class` | 公式 | 仅 `from_class`；**[τ] = 系数 × σb** |
| `tau_manual` | 缺省 | 仅 `manual`；直接取用户填的 `tau_in` |

载荷类别按**整个寿命期内的循环次数**分，不是按载荷大小：

| 类别 | 循环次数 | 典型场合 | 许用应力比 |
|---|---|---|---|
| I 类 | > 10⁶ | 发动机气门弹簧 | **未录入** |
| II 类 | 10³ ~ 10⁶ | 一般机械用弹簧 | **未录入** |
| **III 类** | < 10³ | 安全阀、夹具压紧（基本静载） | **0.5** |

> **I 类与 II 类常被引作 0.3 和 0.4，但没检索到可核对的出处，所以表里留空。**
> 选到这两类会如实报出缺口位置。留空不等于把用户堵死——
> 手上有材料标准的人可以把 `tau_source` 切到 `manual` 直接填 [τ]，
> 两条通路后面的计算完全一致。
>
> III 类的 0.5 有算例复核：C 级碳素弹簧钢丝 σb = 1660 MPa → [τ] = 830 MPa。

### 第 2 步：几何与曲度系数

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `K` | 公式 | **K = (4C−1)/(4C−4) + 0.615/C**（Wahl 曲度系数） |
| `D2` | 公式 | **D2 = C · d**（中径，mm） |
| `D_out` | 公式 | **D = D2 + d**（外径，mm） |

> K 计入簧丝**内侧**的应力集中——弹簧受力时内侧比外侧危险。
> 这是定义式不是查表值，换个 C 必须跟着变。

### 第 3 步：强度

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `d_min` | 公式 | **d ≥ √(8 K F C / (π [τ]))**（mm） |
| `chk_d` | 校核 | d ≥ d_min |
| `tau_actual` | 公式 | **τ = 8 K F D2 / (π d³)**（MPa） |
| `chk_tau` | 校核 | τ ≤ [τ] |

`d_min` 由 `τ = 8KFD2/(πd³) ≤ [τ]` 代入 `D2 = Cd` 反解而来。

### 第 4 步：刚度与圈数

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `n` | 公式 | **n = G d⁴ f / (8 D2³ F)**，圆整到 0.5 圈 |
| `chk_n` | 校核 | n ≥ 2 |
| `k_spring` | 公式 | **k = G d⁴ / (8 D2³ n)**（N/mm） |
| `f_max` | 公式 | **f = F_max / k**（mm） |

> **刚度必须用圆整后的圈数反算。** 直接用未圆整的 n 算出来的刚度，
> 是一个造不出来的弹簧的刚度——报告里那个数没人能按它验收。

### 第 5 步：稳定性

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `b_ratio` | 公式 | **b = H0 / D2** |
| `b_limit` | 查表 | `stability_limits.{end_support}.b_limit` |
| `chk_stability` | 校核 | b ≤ 临界值 |

| 端部约束 | 临界 b |
|---|---|
| 两端固定 | 5.3 |
| 一端固定、一端回转 | 3.7 |
| 两端回转 | 2.6 |

> 压缩弹簧太"高"会像细长杆一样失稳侧弯。
> **超限的对策是加导杆或导套，不是硬改弹簧参数**——
> 弹簧本身没问题，问题在约束。

## 校核条件

引擎实际执行的 **4 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_d` | 钢丝直径 | d ≥ d_min | 改用更粗的钢丝、减小 C、或换更高强度材料 |
| `chk_tau` | 切应力 | τ ≤ [τ] | 加粗钢丝、减小 C、或换更高强度材料 |
| `chk_n` | 有效圈数 | n ≥ 2 | 圈数太少弹簧特性不稳定；减小钢丝直径或增大 C |
| `chk_stability` | 稳定性 | b ≤ 临界值 | **加导杆或导套**，或改用更强的端部约束 |

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| 钢丝直径圆整 | GB/T 1358 的直径系列检索不到可核对数值（付费/图片） | R 系列数值表 |
| 切变模量 G 查表 | 同上，查不到可追溯的出处 | 按材料的 G 值表 |
| I 类 / II 类许用应力比 | 常被引作 0.3 / 0.4，但无可核对出处 | GB/T 1239.2 或手册弹簧篇原表 |
| 自由高度 H0 计算 | 需要节距、支承圈型式、并紧磨平量三组系数 | 相应系数表 |
| 疲劳寿命校核 | 需要疲劳极限曲线与应力比修正 | 疲劳数据 |
| 共振校核 | 需要弹簧固有频率与激振频率 | 可算，但需要额外输入，v1 未做 |
| 拉伸 / 扭转 / 圆锥弹簧 | 各有各的公式与初拉力问题 | 各建一份工作流 |

## 已验证算例

输入：Fmax 200 N，行程 20 mm，φ4 钢丝，C = 6，G = 79000 MPa，
III 类静载 σb = 1400 MPa，H0 = 50 mm，一端固定一端回转。

| 步骤 | 结果 |
|---|---|
| K | 1.2525 |
| [τ] | 700 MPa（0.5 × 1400） |
| D2 / D | 24 / 28 mm |
| 所需最小钢丝直径 | 2.3384 mm ≤ 4 ✓ |
| 最大工作切应力 | 239.25 MPa ≤ 700 ✓ |
| 有效圈数 n | **18.5**（由 18.288 圆整） |
| 高径比 b | 2.083 ≤ 3.7 ✓ |
| 校核 | **4 / 4 通过** |

```bash
python -m mds run spring -s F_max=200 -s F_min=0 -s stroke=20 -s d=4 -s C=6 -s G=79000 -s tau_source=from_class -s load_class=class_3 -s sigma_b=1400 -s H0=50 -s end_support=one_fixed_one_free
```

## 常见问题

- **σb 从哪来？** 按钢丝直径与材料等级查材料标准（如 GB/T 4357 碳素弹簧钢丝），
  或**直接抄供货材质证明书**——后者更可靠，因为同一牌号不同直径的 σb 差别很大。
- **G 填多少？** 从材料证书或厂商样本查。引擎不给默认值，因为找不到可追溯的出处。
- **选 I 类或 II 类算不出来怎么办？** 把 `tau_source` 切到 `manual`，
  从你手上的材料标准直接填 [τ]。或者把那两个系数补进 `spring_design.yaml`（要带出处）。
- **算出来圈数是小数正常吗？** 引擎已圆整到 0.5 圈。总圈数还要加支承圈
  （两端并紧磨平通常加 2 圈），本工作流不算总圈数。
- **稳定性不通过一定要改弹簧吗？** 不要。优先加导杆或导套——
  弹簧参数是按载荷和行程定的，为了凑高径比去改它，等于用一个问题换另一个问题。

## 采购关键词模板

弹簧走 `generic` 模板：**物料名 → 线径 + 外径 + 自由长**

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | 固定为 `压缩弹簧` |
| 线径 / 外径 / 自由长 | **必给** | ✓ `spec` | **三要素缺一卖家无法报价** |
| 材质 | 建议 | ✗ 需人工补 | 碳钢 / 304 不锈钢 / 琴钢丝 |
| 圈数或刚度 | 建议 | ✗ 需人工补 | 标准品按三要素卖，定制件要给刚度 |

```bash
python scripts/procure_link.py build -m generic --set kind=压缩弹簧 --set spec="线径4 外径28 自由长50" --set grade=304不锈钢 -c taobao,1688 --format md
```

> **弹簧专属提示**：线径 + 外径 + 自由长三要素缺一不可，只说"压缩弹簧"没人能报价。
> 货架品的**刚度是不保证的**——同样三要素、不同圈数，刚度可以差一倍。
> 对刚度有要求的场合必须定制并在图纸上标明刚度与公差。
