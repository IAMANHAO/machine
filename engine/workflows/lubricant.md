# 润滑油（链条 / 开式齿轮 / 导轨）选型工作流

> **本文档与 `lubricant.yaml` 的关系**
>
> `lubricant.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是**人读说明与评审物**。两者已逐条对齐（2026-09-22），表格里的「步骤 id」
> 可直接在 YAML 里定位。**改公式先改 YAML，再回填本文档**；若有出入以 YAML 为准。
>
> 本文档旧版包含若干**引擎并未实现**的内容（油膜厚度校核、换油周期、食品级等）。
> 这一版把它们移到了「未实现项」一节并写明原因——**缓存里没有数据支撑它们，
> 编一个公式出来比不做更糟**。

## 基本信息

- 物料类型：润滑油 / 润滑脂
- 主导标准：
  - GB/T 7631.12《润滑剂、工业用油和相关产品（L 类）的分类 第 12 部分：链条润滑油》
  - ISO 3448《工业液体润滑剂 — ISO 黏度等级分类》
  - DIN 8195-12《链条润滑》
  - DIN 51517-3《极压齿轮润滑油 CLP》
  - ISO 6743-9 / AGMA 9004-2009 —— 开式齿轮润滑剂
  - ISO 6743-13《机床导轨润滑剂》
- 主要信源：成大先《机械设计手册》第 4 卷 润滑、Tsubaki 链条润滑指南、
  台湾《油情报》图表 98、Mobil Vactra Oil 系列样本

## 这是一条分支型工作流

三类润滑对象的参数、公式、决策表**完全不同**。分支不用嵌套结构表达，
而是**每一步声明自己的 `when:` 守卫**——条件为假就标 `not_applicable` 跳过。

> `not_applicable`（本分支用不到）与 `skipped`（前面出错所以没跑到）是两个不同的状态。
> 混同会让人以为流程坏了。界面、报告、审计三处都分开措辞。

另一处根本差异：这里的表**不是数值插值网格，而是决策表**——按速度档返回一整组推荐
（ISO VG 候选、基础油、添加剂、典型产品、选用说明）。所以用 `table_pick` 而非 `table_lookup`。

## 选型目标

确定：

1. **ISO VG 黏度等级**（推荐区间，如 VG 150 / 220 / 320）
2. **基础油类型**（矿物 / PAO / 酯）
3. **添加剂**（EP / AW / R&O / 黏附剂 / 抗爬行剂）
4. **推荐形态**（油 / 半流体脂 / 开式齿轮脂）—— 仅开式齿轮分支
5. **典型产品**（厂商牌号）—— 仅导轨分支

> **输出的是一组推荐区间，不是唯一解。** 油品选型本身就有区间，
> 最终取值要结合厂商样本（PDS）与实际工况温度。

## 输入参数

与 `yaml: inputs` 一一对应。分支参数用 `required_when` 声明——**选了哪个对象，才要求填哪组参数**。

### 公共（两项都必填）

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 润滑对象 | `target` | — | `chain` / `open_gear` / `rail` | 三类的计算方法与决策表完全不同，先选对象 |
| 工作温度 | `T_work` | ℃ | −40 ~ 300 | **测温点为摩擦副本体，不是环境温度** |

### 链条分支（`target == 'chain'`）

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 小链轮齿数 | `z1` | — | 9 ~ 120 | |
| 链条节距 | `p_chain` | mm | 4 ~ 120 | 08B=12.7 / 10B=15.875 / 12B=19.05 / 16B=25.4 |
| 小链轮转速 | `n_chain` | r/min | 1 ~ 5000 | |
| 加油方式 | `chain_method` | — | `oil_bath` / `spray` / `hand` / `drip` | **直接决定黏度档，必须与实际装置一致** |

### 开式齿轮分支（`target == 'open_gear'`）

| 参数 | id | 单位 | 域 |
|---|---|---|---|
| 齿轮节圆直径 | `d_gear` | mm | 50 ~ 20000 |
| 齿轮转速 | `n_gear` | r/min | 0.1 ~ 3000 |

### 导轨分支（`target == 'rail'`）

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 丝杠 / 驱动转速 | `n_screw` | r/min | 1 ~ 6000 | |
| 导程 | `lead` | mm | 1 ~ 100 | 丝杠转一圈工作台走的距离 |
| 导轨配副 | `rail_pair` | — | `metal_metal` / `vertical` | 默认金属-金属滑动导轨 |

> **塑-金属配副与滚动直线导轨暂不覆盖。** `rail_viscosity.yaml` 里有这两段数据
> （`slide_rail_plastic_metal`、`rolling_linear_guide`），但没有接进工作流——
> 它们的判据不是速度，硬塞进同一条分支会给出错的推荐。见「未实现项」。

## 计算步骤

共 **22 个 step**。同一条工况只会真正执行其中一部分，其余标 `not_applicable`。

### 公共：可读标签（6 步）

| 步骤 id | when | 产出 |
|---|---|---|
| `label_chain` / `label_gear` / `label_rail` | 各自分支 | `target_label` = 链条 / 开式齿轮 / 导轨 |
| `kind_chain` / `kind_gear` / `kind_rail` | 各自分支 | `procure_kind` = 链条油 / 开式齿轮脂 / 导轨油 |

> `chain` 这种内部值不该出现在给人看的报告和采购关键词里，所以单独转成中文标签。

### 链条分支（4 步）

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `v_chain` | 公式 | **v = z1 × p × n1 / 60000**（m/s） |
| `v_label_chain` | 文本 | `链速 {v} m/s` |
| `chain_speed_class` | 分档 | v < 5 → `low_speed`；v ≥ 5 → `high_speed`（DIN 8195-12） |
| `chain_rec` | 决策表 | `chain_viscosity.by_speed_and_method.{速度档}_{加油方式}` |

`chain_viscosity.yaml` 实际覆盖的**只有 4 种组合**：

| 链速 | 加油方式 | 黏度 cSt@40℃ | ISO VG | 基础油 | 添加剂 |
|---|---|---|---|---|---|
| 高速 (≥5 m/s) | 油浴 `oil_bath` | 77 ~ 117 | **100** | 矿物 / PAO | AW + R&O |
| 高速 (≥5 m/s) | 喷雾 `spray` | 45 ~ 72 | **46 / 68** | 矿物 / PAO | AW + R&O + 黏附剂 |
| 低速 (<5 m/s) | 手加 `hand` | 135 ~ 320 | **150 / 220 / 320** | 矿物 | AW + R&O + 黏附剂 |
| 低速 (<5 m/s) | 滴油 `drip` | 135 ~ 320 | **220 / 320** | 矿物 | AW + R&O + 黏附剂 |

> **其余 4 种组合会如实报「数据缺失」，不会硬凑一个最接近的档。**
> 「低速 + 油浴」是当前唯一已知的真实缺口（表里确实没有）；
> 「高速 + 手工加油」本来就不是个该被推荐的配置，报缺失比给建议更诚实。

### 开式齿轮分支（5 步）

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `v_gear` | 公式 | **v = π × d × n / 60000**（m/s） |
| `v_label_gear` | 文本 | `节圆速 {v} m/s` |
| `gear_speed_class` | 分档 | 见下表（ISO 6743-9 / AGMA 9004） |
| `gear_rec` | 决策表 | `open_gear_viscosity.by_pitch_line_speed.{档}` |
| `chk_gear_open` | 校核 | v ≤ 15 m/s |

| 节圆速 (m/s) | 档 | 推荐形态 | ISO VG 典型 |
|---|---|---|---|
| ≤ 0.5 | `very_slow` | 开式齿轮脂 NLGI 0~1（含 MoS₂/石墨） | 460 / 680 / 1000 |
| 0.5 ~ 2 | `slow` | 半流体脂 NLGI 00~000（喷射式） | 220 / 320 / 460 |
| 2 ~ 5 | `medium` | 半流体脂 / 高黏度闭式齿轮油 | 220 / 320 |
| 5 ~ 15 | `fast` | **闭式齿轮箱齿轮油（强制闭式）** | 100 / 150 / 220 |
| > 15 | `very_fast` | **强制闭式齿轮箱 —— 开式结构不再适用** | 68 / 100 / 150 |

> `chk_gear_open` 会在 v > 15 m/s 时**判定不通过**，并给出「必须改为强制闭式齿轮箱」。
> 这是一条结构适用性校核，不是油品问题。

### 导轨分支（5 步）

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `v_rail` | 公式 | **v = n × L / 1000**（m/min，n 为丝杠转速 r/min，L 为导程 mm） |
| `v_label_rail` | 文本 | `移动速度 {v} m/min` |
| `rail_speed_class` | 分档 | 仅 `metal_metal`；见下表 |
| `rail_rec` | 决策表 | `rail_viscosity.slide_rail_metal_metal.by_speed.{档}` |
| `rail_vertical_rec` | 决策表 | 仅 `vertical`；取 `…by_speed.vertical_or_anti_sag` |

| 移动速度 (m/min) | 档 | ISO VG | 添加剂 | 典型产品 |
|---|---|---|---|---|
| ≤ 5 | `slow` | 32 / 46 | AW + 抗爬行剂 | Mobil Vactra Oil Heavy Medium、FUCHS ECOCUT 1520 |
| 5 ~ 15 | `medium` | 46 / 68 | AW + 抗爬行剂 | Mobil Vactra Oil Heavy、Shell Tonna S2 M 68 |
| > 15 | `fast` | 68 / 100 | AW + 抗爬行剂 + R&O | Mobil Vactra Oil Heavy / Heavy Extra |
| 立式 / 防下滑 | `vertical_or_anti_sag` | 100 / 150 | — | 高黏度或导轨脂 |

> **导轨速度公式的量纲勘误（待核）**
>
> 本文档旧版写作 `v = n × L / 60`，但它自己的判据是「v < 15 m/min」。
> n 取 r/min、L 取 mm 时，n×L/60 的量纲是 **mm/s**，与 m/min 对不上。
>
> 本工作流按 **v[m/min] = n × L / 1000** 实现（1500 r/min × 10 mm 导程 = 15 m/min，
> 与工程直觉相符）。上表已按实现更正。**仍需对照手册原文确认**——
> 这与同步带啮合齿数是同一类转写问题。
>
> 旧版还写着「v < 15 m/min → 滑动导轨；v ≥ 15 m/min → 滚动导轨」。
> 这个判据不成立：**速度不决定导轨类型，导轨类型是设计给定的**。
> 实际的分档是在**已知是滑动导轨**的前提下按速度选黏度档，如上表。

### 公共：温度适用性（2 步）

| 步骤 id | 类型 | 条件 | 不通过时 |
|---|---|---|---|
| `chk_mineral_temp` | 校核 | T ≤ 100 ℃ | 矿物油黏度衰减快、氧化寿命短，改 PAO / 酯类合成油，并按合成油样本重新定黏度档 |
| `chk_low_temp` | 校核 | T ≥ −10 ℃ | 需确认倾点与低温启动黏度，常规矿物油可能泵送困难，选低倾点或合成基础油 |

## 校核条件

引擎实际执行的 **3 项** `check`：

| 步骤 id | 校核项 | 条件 | 适用分支 |
|---|---|---|---|
| `chk_gear_open` | 开式结构适用性 | v ≤ 15 m/s | 仅开式齿轮 |
| `chk_mineral_temp` | 矿物油温度适用性 | T ≤ 100 ℃ | 全部 |
| `chk_low_temp` | 低温流动性 | T ≥ −10 ℃ | 全部 |

## 未实现项

本文档旧版列过、但**引擎没有实现**的校核与输出。原因一律是缺数据，不是缺代码：

| 项 | 旧版写法 | 为什么没做 |
|---|---|---|
| 油膜厚度 | 高速时 h ≥ 0.1 μm | 需要赫兹接触压力、表面粗糙度、卷吸速度等一整套 EHL 计算输入，缓存里一项都没有 |
| 换油周期 | ≥ 2000 h，高温重载减半 | 「2000~4000 h」是经验区间不是算法；厂商差异极大，没有可追溯的统一依据 |
| 添加剂兼容 | 同油不同添加剂不混用 | 这是一条使用须知，不是可判定的数值条件 |
| 食品级 | 接触食品 → NSF H1 | 属于选型**约束**而非计算；表里有 NSF H1 产品清单，但没有接入输入参数 |
| 环境修正（粉尘 / 水汽 / 户外） | 升一档黏度、换稠化剂 | 三张表里都有 `environment_adjustments` 段，但「升一档」缺少可执行的档位映射 |
| 塑-金属导轨、滚动直线导轨 | 表里有数据 | 判据不是速度，需要另一组输入与分支 |
| 链条 Tsubaki SAE 牌号路线 | 按链号 × 温度给 SAE | 已在缓存里，但**与 ISO VG 路线是两套口径**，混用会给出自相矛盾的建议 |

> 缓存里有数据、工作流没用上的部分（环境修正、Tsubaki 表、塑-金属导轨）
> 是**下一步最容易补的扩展点**——数据已经在了，缺的是把判据表达清楚。

## 常见问题

- **链条是否可用润滑脂？** 可以，但只适合低速、密封空间；粉尘环境首选脂。
  销-套筒间隙小，普通脂渗不进去 → 仍建议油润滑。Tsubaki 明确"销与套筒间隙小，
  黏度高的润滑脂无法渗透"。**引擎不做油/脂决策**，`chain_viscosity.yaml` 里有
  `oil_vs_grease_decision` 一段可供人读。
- **VG 100 / 220 对应 SAE 多少？** 大致：VG 100 ≈ SAE 30；VG 68 ≈ SAE 20；
  VG 32 ≈ SAE 10W；VG 220 ≈ SAE 50。精确值查 SAE J300。
- **链条油和齿轮油能通用吗？** 一般可，但链条油要求黏附性 + 渗透性 + 防滴落，
  齿轮油可能太稀或无黏附剂。
- **开式齿轮用闭式齿轮油不行吗？** 不推荐：黏度太低易甩出，抗粉尘差。
  必须用开式齿轮脂或半流体脂——除非节圆速已进 `fast` 档，那时本就该改闭式。
- **为什么导轨不能用液压油？** 金属-金属滑动导轨必须配**含抗爬行剂**的导轨油
  （脂肪酸酯类，0.5~2%），否则低速（5~50 mm/min）爬行严重。
  `rail_viscosity.yaml` 的 `not_to_use` 段列了三类不能用的油。
- **为什么某个组合算不出来？** 决策表只覆盖有依据的组合。
  引擎报「数据缺失」时会指出缺的是哪张表的哪个键，**不会挑一个最接近的档给你**。

## 采购关键词模板

油品采购关键词顺序：**品牌 → 产品线 → 黏度等级 → 油品类别 → 补充等级 → 包装规格**

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 品牌 | 建议 | ✗ 需人工补 | 工业油品牌差异大，缺品牌会混入杂牌分装 |
| 产品线 | 建议 | ✗ 需人工补 | 如 `威达Vactra`、`万利得Tonna`、`GEM 1-68 N` |
| 黏度等级 | **必给** | ✓ `vg` | 写 `VG68`，并备一条 `68号` 写法变体 |
| 油品类别 | **必给** | ✓ `kind` | 导轨油 / 链条油 / 开式齿轮脂 |
| 补充等级 | 可选 | ✗ | `CLP 220`、`NLGI 2`、`NSF H1` |
| 包装规格 | **必给** | ✗ 需人工补 | 工业油注意 18L / 20L / 200L 桶装区分 |

> **引擎只自动填两项**：黏度等级与油品类别。推荐 VG 是个区间，
> 采购关键词只能带一个值，所以取区间的**第一个**（`iso_vg_first`）。
> 品牌、产品线、包装规格需要人按实际情况补——引擎不替你挑品牌。

**分对象示例**（人工补全后的完整关键词）：

| 对象 | 推荐关键词 |
|---|---|
| 金属-金属滑动导轨 | `美孚 威达 Vactra VG68 导轨油 18L` |
| 滚子链 | `链条油 VG100 高温 渗透性`（国内牌子多，可先不加品牌） |
| 开式齿轮 | `开式齿轮脂 NLGI 0 含二硫化钼 16kg` |
| 滚动轴承 / 直线导轨 | `锂基脂 NLGI 2 锂基 复合锂 400g`（本工作流不覆盖） |

**单独生成命令**：

```bash
python scripts/procure_link.py build -m lubricant --set brand=美孚 --set product=威达Vactra --set vg=68 --set kind=导轨油 --set pack=18L -c taobao,tmall --format md
```

> **油品专属防伪提示（必须转告用户）**：工业油是仿冒高发品类，务必认品牌授权店 / 旗舰店，
> 到货核对桶身防伪码与批号，必要时索取 MSDS 与检测报告。低于市场价 30% 以上通常是回收油分装。
> 食品医药场景必须确认 `NSF H1` 认证编号可查。
