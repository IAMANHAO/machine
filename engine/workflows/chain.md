# 滚子链传动（几何与运动学）工作流

> **本文档与 `chain.yaml` 的关系**
>
> `chain.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。

## 基本信息

- 物料类型：滚子链传动（**单排**）
- 主导标准：**GB/T 1243**《传动用短节距精密滚子链、套筒链、附件和链轮》
- 覆盖范围：**链号 05B ~ 24B / 08A ~ 24A 的几何与运动学计算**

**不覆盖**：链号选择、套筒链、齿形链、多排链的排数系数。

## ⚠ 这个工作流不能替你选链号

选链号要查**额定功率曲线**（链号 × 小链轮转速），那是曲线图数据，
缓存里没有——与同步带 `rated_power.yaml` 是同一类问题。

所以**链号是输入**，引擎负责的是链号定下来之后的几何与运动学计算。

## 缓存里只录了节距一列

检索到的滚子链参数表在转载时**列与表头错位**：
把销轴直径当成了内链节内宽、把链板高度当成了极限拉伸载荷。数值不可信。

节距之所以敢录，是因为它**能由链号独立复算**：

```
p = 链号前两位 ÷ 16 英寸 × 25.4 (mm)

08B → 8/16 in  = 0.500 in = 12.700 mm
10B → 10/16 in = 0.625 in = 15.875 mm
16B → 16/16 in = 1.000 in = 25.400 mm
```

唯一的例外是 **05B**：按公式应为 7.9375，标准取 **8.0**（公制例外档）。
测试会逐行校验这条式子。

## 选型目标

确定：节距 p、传动比 i、链速 v、两链轮分度圆 d1/d2、链节数 Lp、实际中心距 a。

## 输入参数

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 链号 | `chain_no` | — | 枚举 | 由额定功率曲线选定后填入 |
| 小链轮齿数 | `z1` | — | 9 ~ 150 | 默认 21。**通常取奇数**，与偶数链节数配合可使磨损均匀 |
| 大链轮齿数 | `z2` | — | 9 ~ 150 | |
| 小链轮转速 | `n1` | r/min | 0.1 ~ 5000 | |
| 初定中心距 | `a0` | mm | 10 ~ 20000 | 工程上常取 (30~50) 倍节距 |

## 计算步骤

共 **11 个 step**。

### 第 1 步：链号与节距

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `chain_code` | 查表 | `chains.{chain_no}.code` —— 真正的链号（缓存键写作 `c08B`，键不宜以数字开头） |
| `p` | 查表 | `chains.{chain_no}.pitch`（mm） |

### 第 2 步：运动学

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `i` | 公式 | **i = z2 / z1** |
| `v` | 公式 | **v = z1 · p · n1 / 60000**（m/s） |

> 链速等于**每秒通过的链节长度**，与链轮分度圆无关——
> 这一点和带传动不同，别套 v = πdn/60000。

### 第 3 步：链轮分度圆

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `d1` | 公式 | **d = p / sin(180°/z)**（mm） |
| `d2` | 公式 | 同上，用 z2 |

### 第 4 步：链长与中心距

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `Lp0` | 公式 | **Lp = 2a/p + (z1+z2)/2 + (p/a)·((z2−z1)/2π)²** |
| `Lp` | 公式 | 圆整到**偶数** |
| `chk_even` | 校核 | 链节数为偶数 |
| `a` | 公式 | **a = p/4 · [ (Lp − (z1+z2)/2) + √((Lp − (z1+z2)/2)² − 8((z2−z1)/2π)²) ]** |
| `a_over_p` | 公式 | **a / p** |

> **链节数必须是偶数。** 奇数链节需要过渡链节，强度会下降约 20%。
> 这也是小链轮齿数通常取奇数的原因——奇数齿配偶数链节，
> 每个链节会依次与不同的轮齿啮合，磨损更均匀。

> `a_over_p` 工程上常取 30~50：过小则小链轮包角不足，过大则松边抖动。
> **引擎只报这个比值，不做校核**——推荐范围没有可核对的出处。

## 校核条件

引擎实际执行的 **1 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_even` | 链节数偶数 | Lp 为偶数 | 必须为偶数，否则需用过渡链节，强度下降 |

## 常见问题

- **链号怎么选？** 查厂商样本或手册的**额定功率曲线**：按小链轮转速与设计功率
  找到所需链号。引擎没有那张曲线，选不了。
- **A 系列和 B 系列有什么区别？** A 源于美国，B 源于英国。
  **同一数字的 A / B 节距相同，但滚子直径、内宽、板厚都不同，不可混用。**
- **为什么小链轮齿数取奇数？** 奇数齿配偶数链节，每个链节会依次与不同轮齿啮合，
  磨损更均匀。
- **中心距算出来和初定的不一样？** 正常。链节取整后中心距要反算微调，
  偏差通常在半个节距以内。安装时应留 2%~3% 的中心距可调量。
- **链速多少算高？** 一般滚子链推荐 v ≤ 15 m/s。**引擎不做这个校核**——
  这个限值没有可核对的出处，请对照手册。

## 采购关键词模板

链条走 `chain` 模板：

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | `滚子链` |
| 链号 | **必给** | ✓ `model` | 如 `08B`。**A/B 系列必须写清** |
| 节数 | **必给** | ✓ `spec` | 如 `138节`。链条按节数卖 |
| 排数 | 建议 | ✗ 需人工补 | 单排 / 双排 / 三排 |
| 品牌 | 建议 | ✗ 需人工补 | 东华 / 椿本 / 大同 |

```bash
python scripts/procure_link.py build -m chain --set kind=滚子链 --set model=08B --set spec=138节 -c taobao,1688 --format md
```

> **链传动专属提示**：链条按**节数**下单，不是按长度。
> 链轮要单独买，且必须与链号匹配（08B 的链只能配 08B 的轮）。
> 接头链节（半节 / 全节）要另外确认——**138 是偶数所以用普通接头，
> 奇数节要过渡链节，强度会降。**
