# 滚动轴承（基本额定寿命校核）工作流

> **本文档与 `bearing.yaml` 的关系**
>
> `bearing.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。

## 基本信息

- 物料类型：滚动轴承（寿命校核）
- 主导标准：**GB/T 6391-2010**《滚动轴承 额定动载荷和额定寿命》（等同采用 ISO 281:2007）
- 覆盖范围：球轴承与滚子轴承的**基本额定寿命 L10**

## 不自建轴承型号库 —— 这是设计选择，不是缺陷

基本额定动载荷 C、静载荷 C0、系数 X 与 Y，**全部由用户从轴承样本填入**。

三个理由：

1. 这几个数印在样本的**同一页**上，抄它们比抄一张来路不明的系数表可靠
2. 不同厂商同一型号的 C 值**确实有差异**，自建型号库反而会给出错的数
3. 样本是每型号一行、成千上万条的数据，不可能核验

引擎负责的是**确定的那部分**：当量动载荷、寿命指数、寿命公式、校核。

## 选型目标

确定：当量动载荷 P、承载能力比 C/P、基本额定寿命 L10h，并与预期寿命比较。

## 输入参数

### 必填

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 径向载荷 | `Fr` | N | 0 ~ 10⁸ | |
| 轴向载荷 | `Fa` | N | 0 ~ 10⁸ | 默认 0 |
| 转速 | `n` | r/min | 0.1 ~ 100000 | |
| 基本额定动载荷 C | `C` | N | 100 ~ 10⁸ | **从样本抄** |
| 滚动体型式 | `rolling_element` | — | `ball` / `roller` | 决定寿命指数 ε |
| 载荷情况 | `load_case` | — | `pure_radial` / `combined` | |
| 载荷系数 fp | `fp` | — | 1.0 ~ 3.0 | 默认 1.2。**按你所用样本的 fp 表取** |
| 预期寿命 | `Lh_required` | h | 100 ~ 500000 | 默认 20000 |

### 分支必填（`load_case == 'combined'`）

| 参数 | id | 域 | 说明 |
|---|---|---|---|
| 径向动载荷系数 X | `X_in` | 0.1 ~ 1.0 | 从样本按 Fa/C0 与 Fa/Fr 查取 |
| 轴向动载荷系数 Y | `Y_in` | 0 ~ 5 | 同上 |

> **引擎不判断 Fa/Fr 与 e 的大小关系**——e 同样要查样本。
> 选「纯径向」这一档前，请自行确认 Fa = 0 或 Fa/Fr ≤ e，**否则结果偏危险**。

## 计算步骤

共 **12 个 step**。

### 第 1 步：载荷系数

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `label_radial` / `label_combined` | 文本 | 结果表里的可读标签 |
| `X_radial` / `Y_radial` | 查表 | 仅纯径向；取 `pure_radial.X` = 1、`pure_radial.Y` = 0 |
| `X_combined` / `Y_combined` | 缺省 | 仅联合载荷；取用户填的 `X_in` / `Y_in` |

> **纯径向时 X=1、Y=0 是定义性的**，不需要查系数表。
> 所以这一档不依赖那张没录入的 X/Y 表，可以直接算。

### 第 2 步：当量动载荷

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `P` | 公式 | **P = fp · (X·Fr + Y·Fa)**（N） |
| `chk_P_positive` | 校核 | P > 0 |
| `C_over_P` | 公式 | **C / P** |

> 寿命对 C/P 是 **ε 次方**关系——C/P 提高一倍，球轴承寿命提高 **8 倍**。
> 所以选型时提高一个尺寸系列的收益，比降一点载荷大得多。

### 第 3 步：额定寿命

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `epsilon` | 查表 | `exponents.{rolling_element}.epsilon` |
| `L10h` | 公式 | **L10h = (10⁶ / (60 n)) · (C/P)^ε**（h） |
| `chk_life` | 校核 | L10h ≥ 预期寿命 |

| 滚动体 | 接触形式 | ε |
|---|---|---|
| 球轴承 | 点接触 | **3** |
| 滚子轴承 | 线接触 | **10/3 ≈ 3.333** |

> ε 是 ISO 281 的**定义值**，不是经验系数。

## 校核条件

引擎实际执行的 **2 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_P_positive` | 当量动载荷有效性 | P > 0 | 径向与轴向载荷都填了 0，无法计算寿命 |
| `chk_life` | 寿命 | L10h ≥ 预期寿命 | 改用额定动载荷更大的轴承、降低载荷、或降低预期寿命要求 |

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| **X / Y 系数表** | 按 Fa/C0 与轴承类型分档，是 GB/T 6391 的正表，检索不到可核对的完整数值 | 标准原表。**但即便补上，样本值仍应优先** |
| **载荷系数 fp 表** | 各厂商样本口径不一致 | 你所用样本的 fp 表 |
| **静强度校核**（C0、P0） | 需要 X0/Y0 系数表 | 该表。低速重载或有冲击时常常是静载荷定型号 |
| 修正额定寿命 Lnm | ISO 281 的 aISO 系数是**三维线图**，读不出数 | 线图数字化 |
| 极限转速校核 | 每型号一个数的样本数据 | 样本 |
| 轴承型号库 | 见上文，**刻意不做** | —— |

## 已验证算例

输入：Fr = 3000 N，纯径向，n = 1450 r/min，C = 30000 N，球轴承，fp = 1.2，预期 20000 h。

| 步骤 | 结果 |
|---|---|
| X / Y | 1 / 0 |
| 当量动载荷 P | 3600 N |
| C / P | 8.3333 |
| ε | 3 |
| **基本额定寿命 L10h** | **约 6651 h** |
| 校核 | ❌ 未达 20000 h 的预期 |

> 这是个**刻意选的不通过算例**：C = 30000 N 的轴承带 3000 N 径向载荷、
> 1450 r/min，寿命只有 6600 多小时。要达到 20000 h 需要把 C/P 提到约 12，
> 即换更大尺寸系列——正说明 ε 次方关系的分量。

```bash
python -m mds run bearing -s Fr=3000 -s Fa=0 -s n=1450 -s C=30000 -s rolling_element=ball -s load_case=pure_radial -s fp=1.2 -s Lh_required=20000
```

## 常见问题

- **C 从哪来？** 轴承样本（SKF / NSK / FAG / 哈轴 / 洛轴…）。
  注意区分 **Cr（径向）** 与 **Ca（轴向）**，本工作流用的是与载荷方向对应的那个。
- **怎么知道该选纯径向还是联合载荷？** 比较 Fa/Fr 与样本给的 e 值。
  Fa/Fr ≤ e 时按纯径向算（X=1、Y=0）；大于 e 时必须查 X、Y。**引擎不替你比**。
- **预期寿命填多少？** 按机械类型。一般机械 8000~12000 h，
  连续运转的重要设备 40000~60000 h。具体应按本单位规范。
- **寿命不够怎么办？** 按 ε 次方关系，优先换大一个尺寸系列（C 提高最有效），
  其次是降低载荷或改用滚子轴承（ε 更大）。
- **为什么不算静强度？** 见「未实现项」。**低速重载场合请务必另行校核 C0**——
  那种工况下轴承往往先被压出塑性变形，而不是疲劳失效。

## 采购关键词模板

轴承走 `bearing` 模板。**引擎只能给出额定动载荷，型号要你自己定**——
因为型号是你从样本里选的，引擎没有那张表。

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | `滚动轴承` |
| 型号 | **必给** | ✗ 需人工补 | 如 `6208`、`30208`。**这是最关键的一项** |
| 品牌 | 建议 | ✗ 需人工补 | SKF / NSK / 哈轴 / 洛轴。品牌差价很大 |
| 游隙 | 视情况 | ✗ 需人工补 | C3 / C4，高温或过盈配合场合必给 |
| 密封型式 | 视情况 | ✗ 需人工补 | -2RS（双密封）/ -2Z（双防尘） |

```bash
python scripts/procure_link.py build -m bearing --set kind=深沟球轴承 --set model=6208-2RS --set brand=哈轴 -c taobao,tmall,jd --format md
```

> **轴承专属提示**：轴承是**仿冒重灾区**，务必认品牌授权渠道，
> 到货核对包装防伪码、内圈激光打标与游隙代号。
> 低于市场价 40% 以上基本可以判定是翻新或仿冒——装上去几个月就会异响。
