# 减速器（传动装置参数与选型转矩）工作流

> **本文档与 `reducer.yaml` 的关系**
>
> `reducer.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。

## 基本信息

- 物料类型：减速器 / 传动装置（**选型前的参数计算**）
- 依据：《机械设计基础》表 3-1「常用机械传动的主要性能」（清华大学出版社）
- 覆盖范围：单级/两级闭式圆柱齿轮、单级闭式圆锥齿轮、蜗杆传动

**不覆盖**：行星齿轮减速器、摆线针轮减速器（教材表 3-1 不含这两类）。

## 这不是型号选型，是选型前的参数计算

引擎算的是**总效率、输出转速、输出转矩与所需公称转矩**。
**具体型号必须由人从厂商样本选**——样本是每型号一行的数据，成千上万条，
自建型号库反而会给出错的数。

## 选型目标

确定：各级效率与总效率 η总、输出功率 P出、输出转速 n出、输出转矩 T出，
以及按工况系数放大后的**所需公称转矩 Tn**。

## 输入参数

### 必填

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 输入功率 | `P` | kW | 0.01 ~ 5000 | 电动机额定功率 |
| 输入转速 | `n_in` | r/min | 1 ~ 30000 | |
| 总传动比 | `i` | — | 1.01 ~ 500 | |
| 传动型式 | `drive_type` | — | 枚举 | 默认单级闭式圆柱齿轮 |
| 轴承对数 | `bearing_pairs` | — | 0 ~ 10 | 默认 2。**效率按「一对」计** |
| 轴承型式 | `bearing_type` | — | 枚举 | 选项读自 `transmission.bearing_pair` |
| 联轴器个数 | `coupling_count` | — | 0 ~ 6 | 默认 1 |
| 联轴器型式 | `coupling_type` | — | 枚举 | 选项读自 `transmission.coupling_efficiency` |
| 工况系数 KA | `KA` | — | 1.0 ~ 4.0 | 默认 1.25。**按所选厂商样本的表取** |

### 分支必填

| 参数 | id | 域 | 何时必填 |
|---|---|---|---|
| 齿轮精度等级 | `gear_precision` | `grade_7` / `grade_8` / `grade_9` | `drive_type != 'worm'` |
| 蜗杆头数 | `worm_thread` | `self_locking` / `single` / `double` / `quad` | `drive_type == 'worm'` |

> 齿轮精度指 **GB/T 10095 的齿轮精度等级**，不是减速器整机精度。

## 计算步骤

共 **15 个 step**。

### 第 1 步：传动副效率

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `eta_cyl` | 查表 | 仅圆柱齿轮；`gear_drive.cylindrical_closed.by_precision.{gear_precision}.eta` |
| `eta_bevel` | 查表 | 仅圆锥齿轮；对应的 `bevel_closed` 路径 |
| `eta_worm` | 查表 | 仅蜗杆；`worm_drive.by_thread.{worm_thread}.eta_min` |
| `eta_drive_two` | 公式 | 仅两级；**η = η单级²** |
| `eta_drive_one` | 公式 | 其余；η = η单级 |

| 传动型式 | 效率 | 常用传动比 |
|---|---|---|
| 闭式圆柱齿轮 7 级 | 0.98 | 一级 3~5，二级 8~40 |
| 闭式圆柱齿轮 8 级 | **0.97** | 同上 |
| 闭式圆柱齿轮 9 级 | 0.96 | 同上 |
| 闭式圆锥齿轮 7 级 | 0.97 | 2~3 |
| 闭式圆锥齿轮 8 级 | 0.96 | 2~3 |
| 蜗杆 · 自锁 | 0.40 ~ 0.45 | 10~40 |
| 蜗杆 · 单头 | 0.70 ~ 0.75 | 10~40 |
| 蜗杆 · 双头 | 0.75 ~ 0.82 | 10~40 |
| 蜗杆 · 三头和四头 | 0.82 ~ 0.92 | 10~40 |

> **区间一律取下端**（偏保守），与教材「一般取中间值」的口径不同。
> 这是刻意的：选型时**低估输出功率会选大一档，高估会选小一档，前者安全**。

> 圆锥齿轮表里**只有 7 级与 8 级**。选 9 级会如实报缺口——
> 不能拿圆柱齿轮的 9 级值顶上，那是两种不同的传动。

### 第 2 步：轴承与联轴器效率

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `eta_bearing` | 查表 | `bearing_pair.{bearing_type}.eta` |
| `eta_coupling` | 查表 | `coupling_efficiency.{coupling_type}.eta` |
| `eta_total` | 公式 | **η总 = η传动副 × η轴承^对数 × η联轴器^个数** |

| 部件 | 效率 |
|---|---|
| 滚动轴承·球（稀油润滑，一对） | **0.99** |
| 滚动轴承·滚子（一对） | 0.98 |
| 滑动轴承·润滑良好（一对） | 0.97 ~ 0.99 |
| 滑动轴承·润滑不良（一对） | 0.94 ~ 0.97 |
| 弹性联轴器 | 0.99 ~ 0.995 |
| 齿式联轴器 | 0.99 |
| 十字滑块联轴器 | 0.97 ~ 0.99 |

> 教材原文的三条注意事项，直接影响怎么用这张表：
> 1. 同类型的几对传动副、轴承和联轴器，要**分别**计入各自的效率
> 2. 若传动副效率已包含其支承轴承，则**不再重复计入**该对轴承
> 3. 查到的是区间时一般取中间值；工作条件差、润滑维护不良取低值
>
> **漏乘一项，输出功率会偏高，选型就会选小一档。**

### 第 3 步：输出参数

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `P_out` | 公式 | **P出 = P × η总**（kW） |
| `n_out` | 公式 | **n出 = n入 / i**（r/min） |
| `T_out` | 公式 | **T出 = 9550 P出 / n出**（N·m） |

### 第 4 步：传动比合理性

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `i_min` / `i_max` | 查表 | 仅单级圆柱齿轮；取常用传动比上下限 |
| `chk_ratio` | 校核 | 仅单级圆柱齿轮；i ≤ 上限 |

### 第 5 步：选型转矩

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `T_required` | 公式 | **Tn ≥ KA · T出**（N·m） |

按此转矩从厂商样本里选型号。

## 校核条件

引擎实际执行的 **1 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 | 适用分支 |
|---|---|---|---|---|
| `chk_ratio` | 传动比合理性 | i ≤ 常用上限 | 改用两级或其它传动型式 | 仅单级圆柱齿轮 |

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| **行星、摆线针轮减速器** | 教材表 3-1 不含这两类 | 厂商样本的效率与传动比 |
| **热功率校核** | 每型号一个数的样本数据 | 样本热功率表。**蜗杆与连续重载工况常常是热功率定型号，务必另行核对** |
| 型号选择 | 每型号一行的厂商数据 | ——**刻意不做** |
| 工况系数 KA 表 | 各厂商样本口径不一致 | 你所选样本的那张表 |
| 传动比分配（多级之间） | 是优化问题，不是查表 | 分配准则与目标函数 |
| 圆锥齿轮 9 级精度 | 教材表只给到 8 级 | 原表 |

## 已验证算例

输入：7.5 kW / 1450 r/min，i = 4，单级闭式圆柱齿轮 8 级精度，
2 对球轴承，1 个弹性联轴器，KA = 1.25。

| 步骤 | 结果 |
|---|---|
| 传动副效率 | 0.97 |
| 轴承效率（单对） | 0.99 |
| 联轴器效率（单个） | 0.99 |
| **总效率 η总** | **0.97 × 0.99² × 0.99 = 0.9412** |
| 输出功率 | 7.059 kW |
| 输出转速 | 362.5 r/min |
| 输出转矩 | 185.97 N·m |
| **所需公称转矩** | **232.46 N·m** |
| 校核 | **1 / 1 通过**（i = 4 在 3~5 内） |

```bash
python -m mds run reducer -s P=7.5 -s n_in=1450 -s i=4 -s drive_type=cylindrical_single -s gear_precision=grade_8 -s bearing_pairs=2 -s bearing_type=rolling_ball -s coupling_count=1 -s coupling_type=elastic -s KA=1.25
```

## 常见问题

- **轴承对数怎么数？** 效率按**一对**计。一根轴两端两个轴承 = 1 对。
  单级减速器有两根轴，就是 2 对。
- **传动副效率里包含轴承了吗？** 教材注(2)：如果已包含，就**不要重复计入**。
  表 3-1 给的齿轮效率不含支承轴承，所以要另算。
- **蜗杆为什么效率这么低？** 蜗杆是滑动摩擦传动。自锁型只有 0.40~0.45——
  用自锁换来的代价很大，**能用机械制动就别靠自锁**。
- **传动比超出常用范围会怎样？** 单级圆柱齿轮会校核不通过，提示改两级。
  蜗杆与圆锥齿轮目前没有传动比校核（只有单级圆柱的上下限录进了表）。
- **为什么算不出行星减速器？** 教材表 3-1 不含它。要做得补厂商样本数据。
- **热功率要不要管？** 要。**蜗杆减速器和连续重载工况常常是热功率定型号**，
  而不是机械强度。引擎不算这个，选型后务必对照样本的热功率曲线复核。

## 采购关键词模板

减速器走 `reducer` 模板：

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | `减速机`。写清型式更好，如 `硬齿面齿轮减速机` |
| 速比 | **必给** | ✓ `spec` | 如 `速比4` |
| 型号 | **必给** | ✗ 需人工补 | 如 `R47`、`NMRV075`。**这是最关键的一项** |
| 安装方式 | **必给** | ✗ 需人工补 | 卧式 / 立式 / 法兰 / 空心轴 |
| 电机功率 | 建议 | ✗ 需人工补 | 带电机的一体机要给 |

```bash
python scripts/procure_link.py build -m reducer --set kind=硬齿面齿轮减速机 --set model=R47 --set spec="速比4" -c taobao,1688 --format md
```

> **减速器专属提示**：下单必须给**型号 + 速比 + 安装方式 + 轴型式**四项，
> 缺一项无法确定货号。带电机的一体机还要给电机功率与极数。
> **蜗杆减速机要问清热功率**——连续运转场合按机械转矩选的型号常常会过热。
