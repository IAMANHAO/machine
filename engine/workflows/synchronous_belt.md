# 同步带选型工作流

> **本文档与 `synchronous_belt.yaml` 的关系**
>
> `synchronous_belt.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是**人读说明与评审物**：讲清每一步在做什么、为什么这么定、边界在哪。
>
> 两者已逐条对齐（2026-09-22）。表格里的「步骤 id」可直接在 YAML 里定位到对应的 step。
> **今后改公式、改参数、改校核，先改 YAML，再回填本文档。** 若发现不一致，以 YAML 为准。

## 基本信息

- 物料类型：同步带传动（梯形齿）
- 主导标准：**GB/T 11362-2021**《同步带传动 节距型号 MXL、XXL、XL、L、H、XH 和 XXH
  梯形齿同步带额定功率和传动中心距计算》
- 相关标准：**GB/T 11361-2018**《…梯形齿带轮》（带轮参数）；GB/T 11616（圆弧齿，本工作流不覆盖）
- 主要信源：成大先《机械设计手册》第 3 卷 第 14 篇、GB/T 11362
- 覆盖带型：**XL / L / H / XH / XXH**（梯形齿五种）

> **标准号勘误**：本文档旧版把《梯形齿带轮》的书名安在了 GB/T 11362 的编号上。
> 那是两份不同的标准——11362 是**额定功率与中心距计算**，11361 才是**带轮**。
> 缓存表 `belt_pitch.yaml` 的 frontmatter 已一并更正。
> `pulley_teeth_min.yaml`（最小齿数属带轮参数）的归属仍存疑，已标待办。

## 选型目标

确定：带型、带轮齿数 z1/z2、节圆直径 d1/d2、节距 pb、标准节线长 Lp、带齿数 z、
实际中心距 a、带宽 bs、带速 v、设计功率 Pd、额定功率 Pr、有效圆周力 F1。

> **压轴力 FQ 不在输出之列。** FQ = KF(F1 + F2) 需要 KF 与 F2（按带型取值），
> 缓存里没有任何一张表给出这两个系数。引擎不编造系数，所以本工作流**只给 F1**。
> 补上数据表后再加 FQ 步骤——见「未实现项」。

## 输入参数

与 `yaml: inputs` 一一对应。**「域」一列是引擎实际执行的取值范围**，超出直接拒绝并指出是哪一项。

### 必填

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 传递功率 | `P` | kW | 0.01 ~ 500 | 电机名义功率 |
| 主动轴转速 | `n1` | r/min | 10 ~ 20000 | |
| 原动机类型 | `prime_mover` | — | 枚举 | 查 K_A 用，选项读自 `condition_factors.prime_movers` |
| 工作机类型 | `work_machine` | — | 枚举 | 查 K_A 用，选项读自 `condition_factors.work_machines` |
| 每日工作时数 | `hours_per_day` | — | 枚举 | 默认「不超过 10 小时」 |

**传动比与从动轴转速二选一**（YAML 里写作 `one_of: ratio`，两个都不给会拦下来）：

| 参数 | id | 单位 | 域 |
|---|---|---|---|
| 传动比 | `i` | — | 0.1 ~ 20 |
| 从动轴转速 | `n2` | r/min | 1 ~ 20000 |

**枚举取值**：

| 参数 | 可选值 |
|---|---|
| `prime_mover` | `ac_motor_normal` 交流电动机（启动转矩正常）／ `ac_motor_high` 交流电动机（启动转矩大、频繁启动）／ `diesel` 内燃机、电动机-液压马达 |
| `work_machine` | `light_uniform` 轻型均匀载荷／ `medium_uniform` 中等载荷／ `medium_impact` 中等冲击／ `heavy_impact` 重冲击 |
| `hours_per_day` | `h_le_10` ≤10 h／ `h_10_to_16` 10~16 h／ `h_gt_16` >16 h（含连续运转） |

### 选填

| 参数 | id | 单位 | 域 | 不填时 |
|---|---|---|---|---|
| 带型 | `belt_type` | — | 枚举 XL/L/H/XH/XXH | 由步骤 `belt_type_sel` 停下来请人决策 |
| 小带轮齿数 | `z1_in` | — | 10 ~ 120 | 取该带型该转速档的 z1min |
| 初定中心距 | `a0` | mm | 10 ~ 10000 | 按 1.35(d1+d2) 初定 |

## 计算步骤

共 **32 个 step**，分属下面 8 段。每行的「步骤 id」即 YAML 里的 `- id:`。

### 第 1 步：设计功率 Pd

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `K_A` | 查表 | `condition_factors` → `prime_movers.{prime_mover}.hours.{hours_per_day}.{work_machine}` |
| `Pd` | 公式 | **Pd = K_A × P**（kW） |

### 第 2 步：带型

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `belt_type_sel` | **决策** | 候选读自 `belt_pitch.belt_types`，附节距、vmax、典型用途 |
| `pb` | 查表 | `belt_pitch.belt_types.{belt_type}.pitch_pb`（mm） |
| `v_max` | 查表 | `belt_pitch.belt_types.{belt_type}.vmax`（m/s） |

> **这一步引擎不替你猜。** 带型要按 Pd 与 n1 查 GB/T 11362 的**带型选择图**，
> 那是图形数据，缓存里没有。所以 `belt_type_sel` 是 `select` 步骤：
> 没预先指定 `belt_type` 时，流程会停在这里，列出候选与各自的节距 / 最大带速 / 典型用途，
> 由工程师或 AI 决策后继续。这是"AI 做不确定的事、脚本做确定的事"在本工作流里唯一的落点。

节距与最大带速（`belt_pitch.yaml`）：

| 带型 | pb (mm) | vmax (m/s) | 典型用途 |
|---|---|---|---|
| XL | 5.08 | 40 | 轻载、仪器仪表、轻工机械 |
| L | 9.525 | 35 | 一般机械传动，最常用 |
| H | 12.7 | 30 | 中等及重载传动 |
| XH | 22.225 | 25 | 重载低速传动 |
| XXH | 31.75 | 20 | 重型低速 |

### 第 3 步：小带轮齿数 z1 与节圆直径 d1

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `speed_bucket` | 分档 | n1 → `n1_le_900` / `n1_900_to_1800` / `n1_1800_to_3600` / `n1_gt_3600` |
| `z1_min` | 查表 | `pulley_teeth_min.pulley_min_teeth.{belt_type}.{speed_bucket}` |
| `z1` | 缺省 | 取 `z1_in`，未给则取 `z1_min` |
| `chk_z1` | 校核 | z1 ≥ z1min |
| `d1` | 公式 | **d1 = z1 × pb / π**（mm） |

> 转速分档是**四档阶跃**，不是插值——1799 r/min 和 1801 r/min 会落到不同档，
> z1min 因此跳变。这是表本身的结构，不是引擎的近似。

在结构允许的前提下 z1 取大：d1 增大 → 啮合齿数增大 → Kz = 1，同时降低每齿负载与弯曲应力。

### 第 4 步：大带轮 z2 与 d2

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `ratio` | 缺省 | 取 `i`，未给则算 `n1 / n2` |
| `z2` | 公式 | **z2 = round(i × z1)**，圆整到整数齿 |
| `d2` | 公式 | **d2 = z2 × pb / π**（mm） |

### 第 5 步：带速校核

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `v` | 公式 | **v = π d1 n1 / 60000**（m/s） |
| `chk_v` | 校核 | v ≤ vmax，不通过 → 减小 z1 或改用小节距带型 |

### 第 6 步：中心距 a 与带长 Lp

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `a0_eff` | 缺省 | 取 `a0`，未给则 **1.35(d1+d2)**（推荐区间中部） |
| `chk_a0_lo` | 校核 | a0 ≥ 0.7(d1+d2)，不通过 → 包角与啮合齿数不足，需加大中心距 |
| `chk_a0_hi` | 校核 | a0 ≤ 2(d1+d2)，不通过 → 带长与振动增加，缩小中心距或加张紧轮 |
| `L0` | 公式 | **L0 = 2a0 + π(d1+d2)/2 + (d2−d1)²/(4a0)**（mm） |
| `Lp` | 圆整 | 向上取 `belt_length_series` 标准节线长（26 档） |
| `a` | 公式 | **a = a0 + (Lp − L0)/2**（mm） |
| `z_belt` | 公式 | **z = round(Lp / pb)** |

> **L0 超出标准节线长系列上限时，结论是「系列内无解」，不是「缺数据」。**
> YAML 里写作 `on_exceed: error`。引擎会告诉你需要多长、系列上限是多少、该怎么改
> （换带型 / 缩小中心距），而**不会**提示你去补数据表——数据没问题，是这个配置超出了标准覆盖范围。

### 第 7 步：带宽 bs

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `zm` | 公式 | **zm = ent[z1 × (0.5 − (d2−d1)/(6a))]** |
| `chk_zm` | 校核 | zm ≥ 6，不通过 → 增大 a 或改用更小节距 pb |
| `Kz` | 公式 | **Kz = 1（zm ≥ 6）；Kz = 1 − 0.2(6 − zm)（zm < 6）** |
| `P0` | 插值查表 | `rated_power`，按 `belt_type_{带型}` 分组，n1 × z1 双线性插值 |
| `bs0` | 查表 | `belt_width_series.belt_width.{belt_type}.bs0`（mm） |
| `bs_req` | 公式 | **bs′ = bs0 × (Pd / (Kz·P0))^(1/1.14)**（mm） |
| `bs` | 圆整 | 向上取 `belt_width_series` 标准带宽（7 档） |

> **啮合齿数公式的转写勘误（待核）**
>
> 本文档旧版写作 `zm = ent[0.5 − (d2−d1)/(6a)] × z1`。按字面理解，ent() 作用于括号内的
> 0.47 左右，取整恒为 0，zm 必然为 0——显然是转写脱漏。
>
> 本工作流按通行写法实现为 **zm = ent[z1 × (0.5 − (d2−d1)/(6a))]**，即**取整作用于整个乘积**。
> 上面的表格已按实现更正。**仍需对照 GB/T 11362-2021 6.3 节原文确认。**

> **P0 表覆盖不足是当前最大短板。** `rated_power.yaml` 每种带型只有 1~2 个示例点。
> 落在已有点凸包外的工况会**如实返回「数据缺失」并报出精确缺口**（缺哪种带型、哪个 n1 行、
> 哪几个 z1 点），**绝不外推**。这比编一个看起来合理的 P0 正确。
> 完整数据需从 GB/T 11362 表 5~8 录入。

### 第 8 步：额定功率与圆周力

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `Pr` | 公式 | **Pr = Kz × (bs/bs0)^1.14 × P0**（kW） |
| `chk_Pr` | 校核 | Pr ≥ Pd，不通过 → 增大 bs 或改用更大节距带型 |
| `F1` | 公式 | **F1 = Pd × 1000 / v**（N） |

## 校核条件

引擎实际执行的 **6 项** `check` 步骤，与 YAML 逐条对应：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_z1` | 小带轮齿数 | z1 ≥ z1min | 增大 z1，或改用更小节距带型 |
| `chk_v` | 带速 | v ≤ vmax | 减小 z1 或改用小节距带型 |
| `chk_a0_lo` | 中心距下限 | a0 ≥ 0.7(d1+d2) | 加大中心距 |
| `chk_a0_hi` | 中心距上限 | a0 ≤ 2(d1+d2) | 缩小中心距或加张紧轮 |
| `chk_zm` | 啮合齿数 | zm ≥ 6 | 增大 a 或减小 pb |
| `chk_Pr` | 额定功率 | Pr ≥ Pd | 增大 bs 或改用大节距带型 |

**「带宽 bs′ ≤ bsmax」不是校核项。** 它由 `bs` 步骤的 `on_exceed: error` 处理：
所需带宽超出标准系列上限时直接判定**系列内无解**，并给出「改用更大节距带型」的出路。
把它做成 check 会产生一个"算出了带宽但不通过"的假象——实际上那个带宽根本不存在。

## 未实现项

以下在本文档旧版里出现过，但**引擎没有实现**，原因都是缺数据而不是缺代码：

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| 压轴力 FQ = KF(F1+F2) | 缓存里没有 KF 与 F2（按带型取值）的表 | 一张带型 → KF / F2 的表 |
| 带型选择（自动） | GB/T 11362 的带型选择图是图形数据 | 把选择图离散成 Pd × n1 → 带型的表 |
| 圆弧齿带（3M/5M/8M/14M） | 走 GB/T 11616，与梯形齿不是一套体系 | 另建一份 YAML + 对应缓存表 |
| 同步带寿命估算 | 厂商差异极大，无可追溯的统一算法 | 厂商样本，且只能按厂商给 |

## 常见问题

- **梯形齿 vs 圆弧齿**：梯形齿 GB/T 11362，圆弧齿 GB/T 11616。圆弧齿允许更高带速、
  传递更大功率，但价格更高。**本工作流只覆盖梯形齿**，圆弧齿需另建 YAML。
- **何时选 XL 而非 L**：功率较小、转速较高、空间紧凑时；L 是中等功率通用选择。
- **同步带寿命估算**：通常以弯曲疲劳寿命给出，约 8000~20000 h（不同厂商差异较大），
  需对照厂商样本。引擎不给这个数。
- **压轴力 FQ**：用于校核轴和轴承的载荷，常被忽略但可能导致轴承提前失效。
  **引擎目前只输出 F1**，FQ 需自行按厂商样本的 KF、F2 计算。
- **为什么算不出 P0**：多半是工况落在了 `rated_power.yaml` 已有数据点的凸包外。
  引擎会报出精确缺口。这不是 bug，是数据没录全——见「数据表清单」。

## 采购关键词模板

同步带采购关键词顺序：**品牌 → 带型 → 带宽 + 节线长 → 物料名**

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 品牌 | 可选 | ✗ 需人工补 | 盖茨 Gates / 三之星 / 国内品牌；进口带贵，国产可替代 |
| 带型 | **必给** | ✓ `model` | `8M` 不要写 `8m`，大小写影响匹配；梯形齿写 `XL/L/H` |
| 带宽 | **必给** | ✓ `spec` | 写 `带宽20`，只说数字卖家无法确认 |
| 节线长 | **必给** | ✓ `spec` | 写 `节线长1200`，同步带按节线长下单 |
| 物料名 | **必给** | ✓ `kind` | 固定为 `同步带` |

`yaml: procure` 自动生成的是**带型 + 带宽 + 节线长 + 物料名**四要素，渠道 `taobao` / `tmall`。
**品牌需人工补**——引擎不替你挑品牌。

**带轮另行搜索**：带轮要给齿数 + 内孔 + 键槽，如 `同步带轮 8M 60齿 内孔25 键槽8`。
本工作流不生成带轮关键词。

**单独生成命令**：

```bash
python scripts/procure_link.py build -m synchronous_belt --set brand=盖茨 --set model=8M --set spec="带宽20 节线长1200" --set kind=同步带 -c taobao,tmall --format md
```

> **同步带专属提示**：带型 + 带宽 + 节线长三要素缺一卖家无法报价；
> 非标长度需找定制厂（交期 7~15 天）。圆弧齿（3M/5M/8M/14M）与梯形齿（XL/L/H）
> 不可混用，搜索时确认是同一体系。
