# 轴（按扭转强度初估轴径）选型工作流

> **本文档与 `shaft.yaml` 的关系**
>
> `shaft.yaml` 是**可执行契约**，由 `mds.runner` 解释执行，是唯一的计算真源。
> 本文档是人读说明与评审物，与 YAML 逐条对齐。改公式先改 YAML，再回填本文档。

> ## ⚠ 这是初估，不是完整的轴设计
>
> 本工作流只按**纯扭转**估算最小轴径，用于结构设计开始前定一个起点。
> 完整的轴设计还需要**弯扭合成强度校核**与**疲劳安全系数校核**，
> 后者要 σ-1、Kσ、εσ、β 等一整套系数表，缓存里一张都没有，因此未实现。
>
> **不要拿这里的结果直接定稿。**

## 基本信息

- 物料类型：传动轴（**实心圆轴**）
- 依据：机械设计手册 · 轴的强度计算「按扭转强度或刚度计算」
- 主要信源：两处手册口径的电子转载（见「数据表清单」的冲突说明）
- 覆盖范围：Q235A/20、35 钢、45 钢、40Cr 系合金钢、1Cr18Ni9Ti 五类常用轴材料

**不覆盖**：空心轴（抗扭截面系数不同）、弯扭合成、疲劳校核、刚度校核、临界转速。

## 选型目标

确定：传递转矩 T、许用扭转切应力 [τT]、按扭转估算的最小轴径，
并给出键槽放大与取整后的轴径，再反算校核。

## 输入参数

| 参数 | id | 单位 | 域 | 说明 |
|---|---|---|---|---|
| 传递功率 | `P` | kW | 0.01 ~ 10000 | |
| 轴的转速 | `n` | r/min | 0.1 ~ 30000 | |
| 轴的材料 | `material` | — | 枚举 | 默认 45 钢。选项读自 `material_stress.materials` |
| 弯矩影响程度 | `bending_influence` | — | `large` / `small` | 默认 `large`（保守）。决定 [τT] 取区间哪一端 |
| 键槽数量 | `keyway` | — | `none` / `one` / `two` | 默认单键槽。选项读自 `material_stress.keyway_allowance` |

> **`bending_influence` 是设计判断，引擎不替你定。**
>
> [τT] 是**已经考虑了弯曲影响而降低过**的许用扭转切应力，所以区间很宽（45 钢 30~40 MPa）：
> - 弯矩很小 / 只受转矩、载荷平稳、单向回转 → 取上端（`small`，轴细）
> - 弯矩较大 / 载荷有冲击 / 双向回转 → 取下端（`large`，轴粗）
>
> 拿不准就用默认的 `large`。

## 计算步骤

共 **10 个 step**。每行的「步骤 id」即 YAML 里的 `- id:`。

### 第 1 步：转矩与许用应力

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `T` | 公式 | **T = 9550 P / n**（N·m） |
| `material_label` | 查表 | `materials.{material}.name_zh`，供结果表与采购关键词显示 |
| `tau_low` | 查表 | 仅 `large`；取 `materials.{material}.tau_low` |
| `tau_high` | 查表 | 仅 `small`；取 `materials.{material}.tau_high` |

| 材料 | [τT] 区间 (MPa) |
|---|---|
| Q235A、20 钢 | 12 ~ 20 |
| 35 钢 | 20 ~ 30 |
| **45 钢（最常用）** | **30 ~ 40** |
| 40Cr、35SiMn、38SiMnMo、42SiMn、40MnB、3Cr13 | 35 ~ 52 |
| 1Cr18Ni9Ti | 15 ~ 25 |

### 第 2 步：估算轴径

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `d_torsion` | 公式 | **d ≥ (9.55×10⁶ P / (0.2 [τT] n))^(1/3)**（mm） |
| `kw_factor` | 查表 | `keyway_allowance.{keyway}.factor` |
| `d_raw` | 公式 | **d′ = d × 系数** |
| `d_shaft` | 公式 | **d = ceil(d′)**，向上取整到整毫米 |

| 键槽 | 放大系数 |
|---|---|
| 无键槽 | 1.00 |
| **单键槽** | **1.05** |
| 双键槽 | 1.10 |

> ## 为什么缓存里没有 A0 系数
>
> 手册通常同时给 [τT] 和一个系数 A₀，用 `d ≥ A₀·(P/n)^(1/3)` 估算。
> 但 **A₀ 不是独立数据，它是 [τT] 的换算结果**：
>
> ```
> τT = T/WT = 9.55×10⁶·P/n / (0.2 d³) ≤ [τT]
>   ⟹  d ≥ (9.55×10⁶ P / (0.2 [τT] n))^(1/3)
>   ⟹  A₀ = (9.55×10⁶ / (0.2 [τT]))^(1/3)
> ```
>
> 手册列 A₀ 是为了让人少按几次计算器。软件没有这个需要——
> **多存一个可推导的系数，只会多一处可能抄错、也多一个读者无从追溯的数字。**
>
> 所以本表只存 [τT]，计算过程里出现的是上面那条真正的公式，而不是一个魔数。
> `tests/test_key_shaft.py` 验证两种写法给出同一结果，并确认由 [τT] 反算出的 A₀
> 落在手册公布的区间内（45 钢为 118~107）。

### 第 3 步：反算校核

| 步骤 id | 类型 | 内容 |
|---|---|---|
| `tau_actual` | 公式 | **τT = 9.55×10⁶ P / (0.2 d³ n)**（MPa），用取整后的轴径反算 |
| `chk_tau` | 校核 | τT ≤ [τT]，不通过 → 加大轴径、改用更高强度材料、或降低传递功率 |

> 反算是为了确认取整与键槽放大没有把结论带反。向上取整只会让轴更粗，
> 所以这一步**理应永远通过**——它守的是取整方向写反（误用 `floor`）这类低级错误。

## 校核条件

引擎实际执行的 **1 项** `check` 步骤：

| 步骤 id | 校核项 | 条件 | 不通过时调整 |
|---|---|---|---|
| `chk_tau` | 扭转强度 | τT ≤ [τT] | 加大轴径、改用强度更高的材料，或降低传递功率 |

## 未实现项

| 项 | 为什么没做 | 补什么才能做 |
|---|---|---|
| **弯扭合成强度校核** | 需要支反力、弯矩图与折合系数 α，属于结构相关计算 | 支承位置与载荷分布输入 + α 取值依据 |
| **疲劳安全系数校核** | 需要 σ-1、τ-1、Kσ、Kτ、εσ、ετ、β、ψσ 等一整套系数表与线图 | 上述全部系数表 |
| 标准轴径圆整 | GB/T 2822《标准尺寸》的 R 系列检索到的都是付费或图片形式，**拿不到可核对的数值** | R10/R20/R40 系列数值表 |
| 刚度校核（挠度、扭转角） | 需要支承跨距与截面变化，属结构计算 | 结构输入 |
| 临界转速 | 高速轴才需要，需要质量分布 | 结构与质量输入 |
| 空心轴 | 抗扭截面系数不同，公式不适用 | 内外径比 β 的输入与相应公式 |

> 取整后的轴径是**向上取整到整毫米**。最终轴径还要由轴承内径、轴肩结构、
> 密封件尺寸共同决定，并按 GB/T 2822 取标准值——那一步引擎不做，因为拿不到系列数值。

### 两处信源的冲突与处理

这不是简单的转写差异，是**两套不同口径**：

| 材料 | 甲（手册转载 A） | 乙（手册转载 B） | 本表取值 |
|---|---|---|---|
| Q235A、20 | 15 ~ 25 | 12 ~ 20 | **12 ~ 20** |
| 35 | 20 ~ 35 | 20 ~ 30 | **20 ~ 30** |
| 45 | 15 ~ 25 ⚠ | 30 ~ 40 | **30 ~ 40** |
| 40Cr 等 | 35 ~ 55 | 40 ~ 52 | **35 ~ 52** |

按 `references/source_priority.md` 的冲突处理规则，取**保守值**（偏安全的那一端）。

> **甲的 45 钢一行未采用**：它给的 15~25 比 35 钢还低，且与 1Cr18Ni9Ti 行数值相同，
> 判为转载时行与材料标签错位。所以 45 钢只有乙一处来源，属单一信源——
> 而 45 钢恰恰是最常用的轴材料。这一点写在了表的 `_todo` 里。

## 已验证算例

输入：45 钢，7.5 kW，1450 r/min，弯矩较大，单键槽。

| 步骤 | 结果 |
|---|---|
| T | 49.3966 N·m |
| [τT] | 30 MPa（45 钢保守端） |
| 按扭转估算的最小轴径 | 20.1921 mm |
| 键槽放大系数 | 1.05 |
| 放大后 | 21.2017 mm |
| **取整后轴径** | **22 mm** |
| 实际扭转切应力 | 23.1952 MPa ≤ 30 ✓ |
| 校核 | **1 / 1 通过** |

对照手册 A₀ 算法：A₀ = (9.55×10⁶/(0.2×30))^(1/3) = 116.8（落在手册区间 118~107 内），
d = 116.8 × (7.5/1450)^(1/3) = 20.19 mm —— **与本工作流完全一致**。

```bash
python -m mds run shaft -s P=7.5 -s n=1450 -s material=steel_45 -s bending_influence=large -s keyway=one
```

## 常见问题

- **这个轴径能直接用吗？** 不能。它是**下限**，用于开始结构设计。
  实际轴径通常由轴承内径决定（轴承内径是 5 的倍数），并要满足弯扭合成与疲劳校核。
- **为什么 45 钢和 40Cr 算出来差不多？** 因为 [τT] 差距不大（30~40 vs 35~52），
  而轴径是三次方根关系——许用应力提高 30%，轴径只减小约 9%。
  合金钢的价值主要在疲劳强度与热处理性能，不在这一步。
- **键槽为什么要放大轴径？** 键槽削弱了抗扭截面。单键槽放大 5%，双键槽 10%，
  取的是信源区间（4~10%）的上端，偏安全。
- **算出来的轴径不是标准值怎么办？** 按 GB/T 2822《标准尺寸》取整。
  引擎不做这一步，因为检索不到可核对的 R 系列数值——见「未实现项」。
- **空心轴能用吗？** 不能。抗扭截面系数 WT 的公式不同，本工作流的结果会偏危险。

## 采购关键词模板

轴料走 `generic` 模板：**物料名 → 材质 → 直径**

| 字段 | 是否必给 | 引擎是否自动填 | 说明 |
|---|---|---|---|
| 物料名 | **必给** | ✓ `kind` | 固定为 `圆钢`。需要调质件可改为 `调质圆钢` |
| 材质 | **必给** | ✓ `grade` | 如 `45钢`、`40Cr` |
| 直径 | **必给** | ✓ `spec` | 如 `直径22`。注意这是**估算下限**，不是最终轴径 |
| 长度 | 建议 | ✗ 需人工补 | 按实际结构定 |
| 热处理状态 | 建议 | ✗ 需人工补 | 热轧 / 调质 / 正火 |

```bash
python scripts/procure_link.py build -m generic --set kind=调质圆钢 --set grade=45钢 --set spec=直径25 -c taobao,1688 --format md
```

> **轴料专属提示**：买圆钢要留加工余量，直径通常比成品大 2~5 mm。
> 45 钢常见的供货状态是热轧，需要调质的要单独说明或自行热处理。
> **不要按这个估算直径直接下料**——最终轴径还没定。
