# 信源优先级与校验规则

## 信源分级

### 第 1 级：国家标准（最高优先级）
- **GB**、**GB/T**（推荐性）：强制性 / 推荐性国家标准
- **JB/T**：机械行业标准
- **HJ/T**、**YS/T** 等行业标准：相关行业
- 适用范围：选型公式、安全系数、关键尺寸系列

> 一份标准通常涉及**特定型号系列**，例如 GB/T 11362 只覆盖**梯形齿同步带**，圆弧齿同步带需查 GB/T 11616 或 ISO 13047。引用前先核对标准的适用范围。

### 第 2 级：权威机械设计手册
- 成大先《机械设计手册》（化学工业出版社）—— 中文机械设计首选
- 濮良贵《机械设计》（高教社）—— 高校经典教材
- 机械工业出版社（机工社）其它权威手册
- 适用范围：工况系数、推荐做法、工程经验

### 第 3 级：国际标准
- **ISO**（国际标准化组织）
- **DIN**（德国）
- **AGMA**（美国齿轮制造商协会）
- **JIS**（日本）
- 适用范围：出口设备、与外方对标的场景

### 第 4 级：知名厂商样本
- 轴承：SKF、NSK、FAG、NTN、Timken
- 同步带：Gates、ContiTech、Mitsuboshi
- 齿轮/减速机：SEW、Flender、Nord
- 联轴器：R+W、KTR、Lovejoy
- 适用范围：特定型号的额定值、选型软件

### 第 5 级：技术文章/教材
- 高校教材、技术博客、学术论文
- 适用场景：补充理解，不能作为唯一依据

## 校验规则

| 类型 | 优先级门槛 | 备注 |
|---|---|---|
| 关键工况系数（KA、Km、Kβ 等） | ≥ 第 2 级 + 至少 2 个信源 | 因直接影响额定功率 |
| 安全系数 | ≥ 第 2 级 | 标准有规定时按标准，否则按手册 |
| 标准系列（齿数、长度、宽度、节距） | = 第 1 级 | 必须以国标为准 |
| 额定功率表 | ≥ 第 1 级（如 GB/T）或第 4 级（厂商样本） | 不同厂商差异大 |
| 选型流程和公式 | ≥ 第 2 级 | 标准中通常给出参照流程 |

## 冲突处理

1. **GB vs 手册冲突**：以 GB 为准（国标是法规层级）
2. **手册 vs 厂商样本冲突**：手册给出范围，厂商样本给出具体值，通常两者都可行，**取保守值**（即偏安全的）
3. **新旧版本冲突**：使用最新版；旧版仅在用户特别要求时使用
4. **不同口径冲突**：明确标注各自的适用条件（如"手册口径"vs"厂商口径"）

## 引用规范

每次引用数据时，写明：

```
依据：<标准号 / 手册章节 / 厂商样本名>
来源：<章节、页码或表号>
适用条件：<什么时候该用这个数据>
```

示例：

```
依据：GB/T 11362-2021 表 3
适用条件：梯形齿同步带、交流电动机
```

## 缓存写入规则

写入 `knowledge/cache/<material>/` 时：

- 每个文件顶部必须有 `data_source`、`last_verified` 字段
- 表头注明"适用条件"
- 标记 `verification_status: verified`（双源确认） 或 `single_source`（需复核）
- 单源数据加 `_todo: 需第二信源核实` 注释

## 责任归属

- **强公式、标准系列**：由 SKILL 引擎严格依据国标
- **系数、推荐做法**：结合手册和用户场景判断
- **无可靠数据**：明确告知、要求用户输入，绝不臆造
